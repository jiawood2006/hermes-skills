# 成片交付自检 + 合成卡参数定值（2026-09-16 复检出片后为准）

> 本文件是**交付前最后一道关**的操作清单。里面的数值为**实测定稿值**，
> **覆盖** `product-pixel-compositing.md` §三（卡片几何/特效参数）与 §五.7（贴片 y 值）、
> 以及 `scene-drama-ad-production.md` §二（旧镜头模板）§六.1/.5 的旧说法。冲突时以本文件为准。

## 一、为什么要专门做一遍复检（教训）

用户一句「**好了吗，你先检查一下**」之后，对**已交付**的 15s/30s 做像素级复检，查出 3 处真实缺陷：

| # | 缺陷 | 修法 |
|---|---|---|
| 1 | 水流渲染成**硬边白矩形条**（一眼假） | 水层加 `GaussianBlur(2.8)`；水膜 7 条 `alpha 40 / width 12`、水珠 26 颗 `alpha 82` |
| 2 | 高亮胶囊（y≈1420）**盖住机身底部的 Haier** | 胶囊一律放 **y≈250 顶部区**（角标 y150、产品顶边 y≈383 之间） |
| 3 | **¥169（字号118·y232）与顶部角标挤在一起** | 字号 **100**、y **270** → 与角标至少留 70px，且不压产品顶边 |
| — | 附带：高光扫过出现**竖直硬边光带** | 梯形加宽到 ~220px、alpha 30，整层 `GaussianBlur(32)` |

结论：**"看起来没问题"不算过检，必须放大到产品区 2~3 倍逐项核**（这是用户那次追问的全部价值）。

## 二、发布前自检清单（逐项必过，缺一项不算交付）

1. **规格**：`ffprobe` → duration / 1080×1920 / 25fps / h264 + aac 齐。
2. **真运动**：`freezedetect=n=-60dB:d=0.8` 数 `freeze_start`，**必须 0**。
   ⚠️ 它**测不出"静图+zoompan"** → 是否"贴图感"只能靠肉眼/视觉复核。
3. **语音落点**：`silencedetect=n=-38dB:d=0.15` 读 silence_start/end 成对 → 每句台词落在**对应镜头内**。
   ⚠️ 别把"句中停顿"误读成"句首静音"：edge-tts 句首静音只有 ~0.18s，正常（我曾据此误判"配音晚 1.3 秒"）。
4. **产品细节**：对**交付文件**（不是中间素材）裁产品区放大 2~3 倍 → 金网有编织网孔（不是色块/粗环）、
   Haier 字母正确、机身渐变锐利。
5. **贴片遮挡**：胶囊/贴纸**不得盖住 Haier 或刀网**（见上表）。
6. **文字不压产品**：¥169 与角标分开、参数条不与产品底边打架。
7. **特效边界**：PIL 画的"水流 / 光扫"必须 `GaussianBlur` 软化。
8. **音轨**：`volumedetect` mean ≈ -20~-26dB、max < -1dB（不削波）。
9. **总时长**：15s 版 ≤15.0s、30s 版 ≤30.0s（平台限制）；把末尾 CTA 镜算进前半段，别少算（我踩过 → 只出 28.08s）。
10. **一份交付文件一份证据**：每轮把核验拼图发给用户（飞书 `feishu_send_image.py`），别只说"已修好"。

## 三、合成卡定稿参数（1080×1920 · PIL，0 元）

| 项 | 定值 | 备注 |
|---|---|---|
| 产品宽 `pw` | **640**（高 ≈1234，官方图 626×1207） | 640 以下才不被裁切；`ycenter` 960（参数卡 1000） |
| 接触阴影 | 椭圆 `alpha 120` + `GaussianBlur(26)` | 垫在产品底部 |
| 缓慢放大 | `sc = 0.95 → 1.00`（整段线性）+ `9·sin(1.7t)` 浮动 | 提供"真运动"观感 |
| 高光扫过 | 梯形宽 ~220、`alpha 30`、`GaussianBlur(32)` | 仅作用于产品 alpha 区内 |
| 水膜 / 水珠 | 7 条（`alpha 40`,`width 12`）/ 26 颗（`alpha 82`），整体 `GaussianBlur(2.8)` | 9 条宽 7 alpha 60 的旧值会出硬边 |
| ¥169 | 字号 **100**、y **270**、金色 `(255,213,74)` + 黑描边，0.62→1.06 过冲弹入 | 旧值 118 / y232 会挤角标 |
| 参数条 | y **1655~1745**、黑底 `alpha 128`、白字 | 字幕在 y1560，不打架 |
| 角标 | y **150**，卡片内已画 | 主流水线**不要再叠 `corner()`**（会双角标） |
| 贴片 | 胶囊 y≈250（产品卡/水洗卡/充电卡）；爆炸贴纸 y≈330（人物镜头顶上方） | 人物镜贴纸 y600 曾糊脸 |

卡片背景 = 对应 AI 镜头**重虚化版**（`gblur=sigma=22~26` + `eq=brightness=-0.18~-0.30`）：
虚化既给真实运动，又把 AI 画错的产品一并抹掉。

## 四、配音装配（一步出片，秒级 · 避免挂死）

```bash
ffmpeg -loglevel error -y -i 静音视频串.mp4 -i s1.mp3 -i s2.mp3 ... \
  -filter_complex "[1]adelay=150|150[a0];[2]adelay=2620|2620[a1];...;\
[a0][a1]...amix=inputs=N:normalize=0,afade=t=out:st=<总长-0.7>:d=0.7,apad=pad_dur=0.4[a]" \
  -map 0:v -map "[a]" -t <总长> -shortest -c:v copy -c:a aac -b:a 160k -movflags +faststart OUT.mp4
```
- ⚠️ **裸 `apad` = 无限静音流**：`-t`/`-shortest` 在 filtergraph 出口不必然终止 → 编码器空转 6 分钟、
  写出 16MB、`moov atom not found`、单进程 110% CPU。必须 `apad=pad_dur=0.4`。
- **别先导 m4a 再 mux**（多一步=多一个挂死点）；音频序号从 `[1]` 起（0 是视频串）。
- 台词时长按 mp3 实测（edge-tts `zh-CN-YunxiNeural --rate=+18%`，每句 1.3~2.1s 有效语音），
  末句结束时间必须 ≤ 视频长度，否则尾字被切（如末句 1.66s 就要放在 ≤13.34s）。

## 五、重出流程（改卡片后要重渲染哪些）

1. 改 `make_cards.py` 参数 → **按需重建卡片**（支持 `python3 make_cards.py hero wash spec` 选择性子集，省 3~4 分钟）。
2. 重跑镜头渲染 → 只重渲**含该卡片的镜头**；其余镜头片段可复用（`v3a*/v3b*.mp4`）。
3. 重新 concat + 一步 mux（`assemble*.py` / `final30.sh`）→ 秒级。
4. 重跑本文件第二节清单 → 发用户。
