# 选角 + 参考图完整性：会让成片「看着假 / 产品不像」的坑（2026-09-17 实证，花了 5 轮换来）

> 配套读：`references/realism-and-candid-style.md`（**拍法层**：旁白＋抓拍／暖色实用光／真实皮肤）。
> 本文管**选角层 + 参考图层**：**参考图里有什么，成片里就有什么** —— 图能压住文字，文字压不住图。

## 坑 1（最贵）：人像参考图决定胡子与表情，视频 prompt 完全压不住

症状：成片里男主**长出小胡子、眉毛紧皱**。我在**视频** prompt 里写「上唇绝对没有胡须」「不要皱眉」→ **无效**（v14 实测）。
根因：**候选图生成时就带上了**。旧候选 prompt 写了「淡淡胡渣」＋「表情自然放松、抓拍感，不是看镜头的商业摆拍」，
`wan2.6-t2i` 直接理解成**八字胡/山羊胡 ＋ 严肃皱眉脸**（4 张候选全中）；r2v 照参考图复刻。
**换掉参考图（干净带笑版）后，三段成片的胡子/皱眉/面部色块全部消失 ✓。**

### 候选 prompt 必须写死的六条（实测 4 张候选无胡须、眉眼放松、带笑、仍写实）
```
真实摄影照片，半身人像，不是影棚商业模特照。
上唇必须完全光洁：上唇上方没有任何毛发、没有小胡子、没有胡子阴影；下巴和下颌也剃得干干净净。
下巴、上唇、下颌的肤色必须和脸部完全一致：是干净的肤色，绝不能出现发绿、发青、发灰的胡须阴影或色块。
看着镜头自然地笑：嘴角上扬、露出一点牙齿、眼睛因为笑微微眯起；眉毛放松舒展、不皱眉、不浓眉，眼神温和亲切。
看起来年轻：面部紧致、不超过30岁的样子，发量正常不秃。
半身构图：能看到肩膀和胸部以上，头顶留一点空间，不要只拍脸部特写。
皮肤是真实皮肤：可见毛孔、细纹、肤色不完全均匀；不要磨皮、不要塑料感、不要网红脸。
光线是室内自然光或真实实用灯，有明确方向、有明暗过渡与真实阴影，不要平光、不要打光板感。
背景是真实生活/办公空间（有生活道具、轻微杂乱），有景深虚化。画面中不要出现任何文字、水印、logo。
```
再各加一句设定（年龄/眼镜/衣着/在哪/在干什么）。生成脚本套路见下节。

### 验收候选图：**2 倍放大只看三处**
**上唇（有没有胡子/胡子阴影）· 眉毛（皱不皱、浓不浓）· 表情（带不带笑）**。
不合格 1 分钟就重出，别省 —— 一张带胡子的参考图会让后面每一段成片都长胡子。
⚠️ 别在小缩略图/4 格拼图上判颜色：我曾在拼图里判「U/W 下巴发绿」，放大后完全干净 ——
**色偏是缩放/JPEG 伪影**，据此否定候选会被用户当场纠正。放大后再下结论。

## 坑 2：参考图裁剪不完整 → 模型照抄错形态（产品被画成"矮胖易拉罐"的主因之一）

作"粗细比例参照"的那张官方「真手握产品」图，我只裁了产品上半截（下半截被手挡住）→
模型照它把机身画成**短粗圆柱（长:径 1.25，真机 1.9）** ✗。
**规则：任何当"比例参照"的参考图必须露出产品的完整长度**，并在 prompt 注明
「这张图里被手挡住的部位不用管；不要抄这张图的服装、背景、手势、色调」。
修正版 = 官方拉页图里「手握着整机、从头到脚可见」的那一格（本案：`hand_full.jpg`）→ 长:径回到 1.8~2.03 ✓。

## 坑 3：两个"以为不行其实行 / 以为行其实不行"

| 事项 | 实测结论 |
|---|---|
| 分辨率 | **一律 720P**。同 prompt 下 **1080P 会把机身画成矮胖罐（长:径 1.25）**，720P 才 1.9~2.03 ✓（还便宜：0.6 vs 1 元/秒）|
| 参考图数量 | **5 张可提交**（正面＋真手全长＋刀网微距＋底部端面＋人物），一次通过 ✓ |
| 刀网颜色 | 只写文字（"浅金色"）→ 模型画成**银灰/深灰平盖** ✗；**加一张刀网微距参考图** ＋ 写「黑环宽而明显、网格每根细线都是暖金色、高光时也不会变白变银」→ 出金 ✓ |

## 用户选角行为（实测，照做能省一轮）
- **他按"真实感"挑**：会自己截一张图回来说「**这个很真实**」= 就选它。
  **不要用"构图太紧、肤质偏光滑"去否掉他挑的人** —— 我差点这么干；脸特写反而**更适合当参考图**
  （五官信息量大 → 跨段一致性更好）。
- 他一次可能要多个（回「M和O」= 两版都看），但**先用第 1 段（正脸最多）出两版比脸**再定，省一半钱与时间。
- 生成候选 → 拼 4 格带标签图发飞书让他挑（他回得很快）。候选脚本套路（`wan2.6-t2i`）：
  `POST /api/v1/services/aigc/multimodal-generation/generation`，
  `{"model":"wan2.6-t2i","input":{"messages":[{"role":"user","content":[{"text": COMMON+设定 }]}]},
    "parameters":{"prompt_extend":true,"watermark":false,"n":1,"size":"720*1280"}}`
  → 取 `output.choices[0].message.content[0].image` 下载；**连续多张会被限流**，加 4 次重试 + `sleep 8`。
