## 一、肖像权与合规红线

### 1.1 【铁律】肖像权：真人照片只取风格，不取脸

**用户原话**：「我发的人物照片不要完全按照照片来，那是真人的形象，容易造成肖像权问题，参考就行」

场景：用户发来一张真人照片或 AI 头像（例如水印为「豆包AI生成」的商务男士形象图），
接着说「像这种」/「参考就行」。**这时不要照着他的脸生成。**

正确做法：
1. **纯文字生成原创脸**（**不把那照片喂给模型**）—— 只保留他要的**风格元素**：
   眼镜 / 西装 / 领带 / 年龄段 / 气质 / 场景调性。
   生成 prompt 里可以直接写「黑色方框眼镜，深色西装＋白条纹衬衫＋蓝色条纹领带，27岁左右中国男性」这类风格描述。
2. 出 3~4 个候选 → 拼图发飞书让他挑（他回得很快）。**别自己拍板选脸** —— 换角是口味问题。
3. **核对新脸与照片不是同一个人**（脸型、五官结构要明显不同），并尽量选**中性、不像明星**的脸型
   （像明星的脸同样有肖像权风险）。
4. 已经**照脸生成过**的成片要**撤下、不投放**：本项目把这版移到 `视频/_停用_真人形象版/`，并在消息里明确告知用户。
5. 用户没说"用我"，就默认照片上的人**不是他本人** —— 不要把它当品牌代言人用在对外物料。

配套：换角后**所有含袖口/衣着的段落都要一起重出**（西装 ↔ 衬衫不能混），
水洗/充电这类"没有人脸但有手和袖子"的段落最容易漏。

### 1.2 选角偏好

- 男主 = **年轻阳光 · 斯文商务**、亲和带笑；**避免凶相 / 浓眉 / 有胡子**。
- 候选统一写死「不要皱眉、不要浓眉怒目、眼神温和亲切」，只变年龄/职业/穿着
  （温和商务40 / 亲切邻家40 / 阳光年轻28 / 儒雅斯文50）；实测用户直接回「阳光年轻的样子最好」。
- 用户**按"真实感"挑**：会自己截一张图回来说「这个很真实」= 就选它。
  **不要用"构图太紧、肤质偏光滑"去否掉他挑的人**；脸特写反而更适合当参考图（五官信息量大 → 跨段一致性更好）。
- 他一次可能要多个（回「M和O」= 两版都看），但**先用第 1 段（正脸最多）出两版比脸**再定，省一半钱与时间。

### 1.3 【铁律】人像参考图决定成片的脸：文字压不住图

**铁律：参考图里有什么，成片里就有什么 —— 图能压住文字，文字压不住图。**

三条「写进 prompt 也压不住」的硬事实（必须靠素材/构图解决）：
1. **参考人像会原样决定视频人物的胡子与表情**——候选图带小胡子/皱眉，视频里就是小胡子/皱眉，
   在视频 prompt 里写「上唇绝对没有胡须」「不要皱眉」**完全无效**（2026-09-17 实测白亏 4 轮）。
   → 人像候选必须写死：**上唇完全光洁 + 下巴只有极淡青灰胡渣 + 眉毛放松不皱 + 看着镜头自然微笑 + 看起来年轻**。
   参考图下巴的**青色胡影**会原样带进视频（实测 U/W 两版都有）。
2. **机身会被拉长**——prompt 写「总长≈直径1.9倍」，模型仍按"电剃须刀=细长罐"画成 **2.56**（+35%）。
   → 三条同时上：写 **1.8** ＋说**短圆柱**＋**换机位**（别竖举到脸前，改斜握胸前、机头朝斜上方）。
3. **产品小到画面高 1/10 以下时机头糊成深色块**。
   → 给足尺寸（≥1/6 画面高）＋写「机头朝上、黑环＋金网清晰可辨、机身完整不糊」。

候选图验收：**2 倍放大只看三处** —— 上唇（有没有胡子/胡子阴影）· 眉毛（皱不皱、浓不浓）· 表情（带不带笑）。
不合格 1 分钟就重出，别省 —— 一张带胡子的参考图会让后面每一段成片都长胡子。
⚠️ 别在小缩略图/4 格拼图上判颜色：色偏是缩放/JPEG 伪影，据此否定候选会被用户当场纠正。

### 1.4 合规交付红线（全片，每片必查）

- **全片不放价格**（2026-09-17 用户明令：「视频里面不要体现价格，因为价格经常变化」）。
  做法：`overlay_cfg.json` 删掉 `price` 键（`assemble_r2v_overlays.py` / `assemble_v12.py` 会自动跳过），
  15s 脚本里也要删 `ov_price.png`。**尺寸重量类参数条（74×39mm / 70g / Type-C）可留。**
- **画面不出现文字 / 字幕 / 水印 / 乱码 / 其他品牌 logo**
  （prompt 通用尾巴：`画面中不要出现任何文字、字幕、水印。`）。
  平台自带水印关掉：`parameters.watermark = false`（平台水印文案固定"AI生成"，我方自己加合规标注更好控制）。
- 右下角常驻合规标注「**AI 生成内容 · 广告**」（项目字段 `assembly.compliance`；
  `scripts/gen_ass.py` / `assemble_r2v_overlays.py` / `templates/ad_project.hsq1.json` 已内置）。
- **公开仓库 / 对外内容不留手机号等个人联系方式。**
- 话术口径铁律：台词/口播/花字**只许引官方宣传物料原文**（拉页图、主图上的字）；
  ❌ 属性表"卖点"字段 ≠ 话术；❌ 参考样片/竞品片里听来的说法不得当话术（HSQ1 实测：禁用"鸡蛋大小"）。

### 1.5 分镜纪律：不能只罗列场景（2026-09-17 用户反馈）

原话「人物太呆滞，而且没有情景，单纯的罗列场景，能不能丰富一下」。
反例（写出来的）：电梯镜只有「他走进电梯间，步伐自信，镜头跟随」。
正解：每个镜头给**动作链＋动机＋表情变化** ——
「低头看手表 → 对着不锈钢门板上的倒影理衬衫领口 → 抬头，眼神从疲惫转为自信」。
自检：这个镜头主角**为什么**做这个动作？有没有前后两拍的变化？
另：**「全程没有人直视镜头」要显式写**（否则成片是摆拍/呆滞感）。

## 二、参考图规范与覆盖

### 2.1 数量 / 顺序 / 托管

- **参考图 ≤5 张**（实测 5 张 = 产品正面＋真手全长＋金网微距＋底部端面＋角色图，一次通过 ✓）。
- **顺序必须与锁模板里的「图1..图5」描述一一对应**：项目 JSON 的 `refs` 顺序 = 图1..图N，
  prompt 里用「图1/图2/图3/图4」逐张说明每张的用途。
- **只吃公网 URL**：裁到主体或局部 → 转 JPG（去透明通道，r2v 不支持 rgba）→
  `scp` 到 `/opt/yunvela-site/dh/` → `curl -o /dev/null -w '%{http_code}'` 必须 **200**
  （回读校验：字节数 + md5 一致）；再用 vision 确认画面里没有多余主体。
- 尺寸限制：宽高 240~8000px、宽高比 1:8~8:1、≤20MB；**每张参考图只放一个主体**（硬约束）。
- 上传后**回读校验**：`curl -o /dev/null -w '%{http_code}' https://yunvela.com/dh/<file>` 必须 200；
  再用 vision 确认画面里没有产品/手。

### 2.2 ⚠️ wan3.0-video 会把参考图1 当「画面首帧」

`wan3.0-video` 用 `input.images`（多参考图）时，**把参考图1 当作画面首帧**。
实测：三条不同钩子的开场 0.8 秒**长得一模一样** —— 全是同一张金网刀网微距（我们把图1 设成"刀网微距（金色校准）"）。
**修法**：要"开场就是他本人"→ **把图1 换成男主图**
（代价：少一个金色校准锚点，刀网金色有变浅风险，**换完必须重核刀网**）。
**核验要求**：抽帧核验**必须含首帧（0.2~0.5s）** —— 只看中后段会完全漏掉这类系统性问题。

### 2.3 参考图要"覆盖会被挑错的每个面"（不是"只留同一个视角"）

**通用规则：产品上任何用户会挑错的部位（接口 / 按键 / logo / 刀网纹理 / 粗细），
都必须有一张参考图能看见它。** 看不见的部位，写多少文字约束都挡不住模型自己编 ——
本项目"充电口画错"改 3 轮文案全无效，补一张参考图当场解决。

| 症状 | 真因 | 修法 |
|---|---|---|
| **Type-C 口被画到机身正面** | 只喂了正面图，模型**没见过底部端面**，只能自己编 | 补官方底部视图（`3.png`：端面电源键同心环 + Type-C 插孔 + 指示灯）当第 3 张参考图 → 正面/侧面开孔归零 |
| **机身被画成矮胖杯**（长:径 1.3~1.5，真机 1.9） | 没有任何一张图能提供"粗细"参照 | 补官方**真手握持局部**（裁掉人脸、只留手＋机身、避开画面原有文字）当第 4 张参考图，prompt 写「图4 只用于参照粗细，不要抄它的色调/背景/服装/构图」 |
| **参考图裁剪不完整** | 只裁了产品上半截（下半被手挡住）→ 模型照它画成短粗圆柱（长:径 1.25，真机 1.9）✗ | 任何当"比例参照"的参考图**必须露出产品的完整长度**，并在 prompt 注明「这张图里被手挡住的部位不用管；不要抄这张图的服装、背景、手势、色调」 |

❌ 已作废（2026-09-17）：参考图两张必须"同向同形态"、禁止混入俯视/仰视/断面图
→ 现：正面图 + 官方底部端面视图 + 真手握持局部，三张一起喂，产品反而最准；
当初"变矮胖杯"的真因不是"多了一个视角"，而是**参考图没有覆盖到关键部位**。

### 2.4 参考素材纪律（放参考前逐张放大核对）

1. **人物参考必须用"真实拍摄"素材**
   - AI 生成的磨皮人物图当参考 → 出片**必然是 AI 磨皮脸**（皮肤无毛孔、牙齿假白、发丝塑料光）。
   - **提示词压不住**：实测加了「真实摄影质感、皮肤有自然纹理与毛孔、淡妆、牙齿自然不发白、不磨皮」+
     负面「塑料感、过度磨皮、网红脸、假白牙、油光」，输出依旧磨皮。
   - **正确来源：翻客户官方物料**（本项目 HSQ1 拉页里就有真人素材）：
     `拉页图-5.jpg` 男士侧脸特写（真实毛孔/胡渣）→ **最佳人物参考**；
     `拉页图-2.jpg` 商务男士全身、`拉页图-8.jpg` 使用场景（仰头闭眼）；
     `拉页图-4.jpg` 四场景小图（车载/商务办公/浪漫约会/出差旅行）→ 场景参考；
     `拉页图-7.jpg` 顶部金网+黑环带结构特写 → 产品结构参考；
     `拉页图-9.jpg` 水洗/刀头 + Haier 产品图；`拉页图-13.jpg` 基本参数（74×39×39mm / 70g / 5V / 5W）。
   - **检索顺序**：官方拉页/主图/详情页的**真人素材** → 客户自有资产，无版权风险、真实感最好 → 再考虑 AI 生成。
2. **参考图集里绝不能混入"形态错误"的图（污染）**
   - 实测：把一张 AI 图（里面的人手持**齿状梳刀头+细长机身+圆钮**的错误产品）当第 3 张参考喂进去后：
     模型在冲突参考间摇摆 → 万相中景画成"推子"、可灵头顶长成"蘑菇头"、帧间漂移。
   - **做法**：人物参考图**必须裁到不含产品**（本项目把 girl 图裁成只有脸+发，去掉手和产品）；或干脆不传人物参考图。
3. **产品比例必须来自官方尺寸，且逐帧放大核对**
   - 尺寸以官方参数为准（HSQ1 = 74×39×39mm → **高:宽 1.93:1**）。
   - 交付前**放大逐帧**看，别凭整体观感下结论（本项目两次因为"整体看着还行"误判）。
   - 参考图上传前先量「产品实体 高:宽」：`正面图.png` 625×1206 = **1.93:1** ✅；
     服务器旧 `hsq1_side.jpg` **0.94:1（底面断面图）** ❌ —— 就是它把产品害成"矮胖罐"。
     ⚠️ 阈值分割自动取外接框时 ROI **不要贴边**，否则会把背景暗部框进来，比例全错。
4. **分辨率：生成一律 720P**（同 prompt 下 **1080P 会把机身画成矮胖罐**、金网丢色、logo 漂移），
   成片由装配器升到 **1080×1920**。
   ❌ 已作废（2026-09-18）：原生 1080P 生成 → 现：720P 生成 + 装配升 1080。

### 4.2 开跑前 60 秒自检（省一整轮 6 元/13 分钟）

- [ ] 每个"用户会挑错的部位"都有对应参考图吗（接口/按键/logo/网纹/**粗细比例**/底部端面）
- [ ] 参考图 **≤5 张**、顺序与锁模板「图1..图5」**一一对应**、全部**公网 URL 且 curl 200**
- [ ] 比例参照图**露出产品完整长度**了吗
- [ ] 人像参考图 2 倍放大过**上唇/眉毛/表情**了吗
- [ ] 分辨率是 **720P** 吗
- [ ] 每镜**地点**都写进 prompt 了吗（否则模型自己换场景：车内镜→卧室镜）
- [ ] 引擎是 `wan3.0-video` 时，**图1 是不是你要的首帧**？

### 4.3 常驻验收红线（每片必查）

1. 产品在场景里的**手部接触/光影/透视**是否自洽（不是"看起来像"，是"真的在那儿"）
2. 网面 = 香槟金色放射状网格（同心圆＋放射线交织成菱形小格）、外圈宽黑环 · **Haier** 五字母完整正确
   （⚠️ 原红线写"浅金色**蜂窝编织**"，已作废，见 §三）
3. **接口/按键位置**与官方图一致（侧面有没有开孔都要核）
4. 三段**音色一致**（基频段间差 ≤15%）
5. 字幕时间轴用 `-ss` 精确抽帧核对（**别用 `fps=1/N` 抽样判断时间轴**）
6. 音频装配不用裸 `apad`、不乱加 `-shortest`（会截断视频）
7. 交付到飞书后**回读消息列表**确认送达

### 4.4 成片级交付验收（逐段通过 ≠ 成片通过）

装配后抽帧 9~10 格（覆盖每句字幕、每个花字的起点）一次核完：

- [ ] 每句**字幕**文字正确、无遮挡、无错位
- [ ] 花字/参数条文字正确；**画面里没有任何价格**（价格条已删，参数条只留尺寸/重量/接口）
- [ ] 右下角「**AI生成内容 · 广告**」合规标注在位
- [ ] 无乱码文字、无水印、无多余接口
- [ ] `ffprobe`：30s 版 = `30.000000`、15s 版 = `15.000000`、`1080×1920`
- [ ] 交付 = 覆盖桌面既有交付名，**旧版先改名归档**再覆盖
- [ ] 飞书回显「视频: 0 success」= **成功**
