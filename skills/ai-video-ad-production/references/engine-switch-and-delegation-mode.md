## 2) `make_ad.py` 换引擎（已落地，不用改代码）

项目 JSON 加一行即可：

```json
{ "runid": "wh", "model": "wan3.0-video", "duration": 5, "resolution": "720P", "ratio": "9:16", "...": "..." }
```

`step_submit` 已按引擎分流：

- **`wan3.0-video`** → `input.images` = **URL 列表**，并自动加 `parameters.watermark = False`（默认可能带水印）；
- `wan2.7-r2v` → 仍走 `input.media = [{type: reference_image, url}]`。

⚠️ **`duration` 是项目级参数** → 不同时长的段要拆成**多个项目 JSON**（R2V/wan3.0 一次提交只能一个时长）。
本轮做法：A 组 = 3 个钩子各 5s（`project_w30_hooks.json`）；B 组 = 镜前正片 10s + 车内段 10s（`project_w30_body.json`）。

## 3) 重做镜头的最小代价路线（复用已通过的部分）

换引擎**不必整片重来**：只重生成"画面里有产品"的段，其余段沿用旧产物，然后用 `--steps assemble,deliver`
（**0 元**）重建全部成片：

1. 归档旧成片到 `_停用_<原因>版/`（保留证据，不覆盖）；
2. 改片段引用：把变体/主片 JSON 里的旧 mp4 换成新生成的 mp4（只改引用，不生成）；
3. `make_ad.py <项目.json> --steps assemble,deliver` 重建 6 条变体 + 30s/15s 主片。

## 4) 用户委托模式（原话：「我不专业，还是按照你的建议来做」）

用户这样表态时：

- ❌ 不要再抛选项让他挑（他刚说过"听你的"）；
- ✅ **直接执行自己推荐的那一档**，执行前用一句话说清：做什么 / 花多少钱 / 多久；
- ✅ **分段主动报进度**（开跑时一句、跑完核验后一句），不等他问；
- ✅ 花完把**账目报清**（本次：3 钩子 9 元 + 两段 10s 12 元 = 21 元；装配/切条/交付 0 元）；
- ✅ 顺手把工程债清掉并告知（本轮：`make_ad` 支持 wan3.0、旧成片自动归档），让下次一条命令就能跑。
