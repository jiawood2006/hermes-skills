# 15s 钩子变体批量跑（2026-09-18 实测：6 条一次跑通）

用户会说「**跑 6 条看看**」——即按素材工厂打法做钩子 A/B：**3 种钩子 × 2 个场景 = 6 条 15s**。
目标不是"再出一条大片"，而是**一次拿到 6 个可投放素材，用真实数据淘汰**。

## 1. 省钱的批量结构（关键）
| 部分 | 做法 | 成本 |
|---|---|---|
| **钩子段** | 3 段**新生成**（各 5s，钩子各不同）| 5s×0.6 元 = **3 元/段**，共 9 元 |
| **正片段** | **复用已通过核验的老素材**（各 10s，从既有 seg 取）| **0 元** |
| 装配/切条/交付 | `assemble,deliver` | **0 元** |

→ 6 条成片只花 3 段的钱。**同场景的两条差异只在开头 5 秒** = 变量唯一，
投放后才能判断"是哪个钩子在起作用"（这是有意的对照设计，交付时要主动向用户说明）。

## 2. 用 make_ad 跑（`assembly.order` 支持直接引用已有文件）
```python
"assembly": {
  "order": [
    {"file": "/tmp/r2v/hooks2_h1.mp4", "label": "钩子(冲突型)"},   # 新生成的 5s 钩子
    {"file": "/tmp/r2v/v12_v20_seg1.mp4", "trim": 10, "label": "车内"}  # 复用老素材
  ],
  "total": 15.0,
  "vo": {"file": "vo15_v1.mp3", "voice": "zh-CN-YunxiNeural", "rate": "+5%", "build": True},
  "subs": [
    {"text": "<钩子台词>", "start": 0.7,  "end": 4.6},
    {"text": "<正片卖点台词>", "start": 6.2,  "end": 10.2},
    {"text": "<CTA>", "start": 11.0, "end": 14.5}
  ],
  "chips": [{"text": "70mm迷你机身 · 轻巧便携", "start": 6.0, "end": 10.5}],
  "spec": {"items": ["74×39mm", "70g", "Type-C"], "start": 11.5, "end": 15.0},
  "compliance": "AI 生成内容 · 广告"
}
```
- `{"file": ...}` = **直接复用已有片段**，不必按 `<runid>_<seg>.mp4` 命名 → 新钩子配老正片就靠它。
- 每条变体跑一次 `make_ad.py <变体.json> --steps assemble,deliver`；
  `deliver.name_main` 写成人能看懂的名字（如 `01_冲突_车内_15s.mp4`）。
- ⚠️ **6 条必须串行跑**（共用 workdir，`overlay_cfg.json` 与 `ov_*.png` 会被互相覆盖）。
- ⚠️ 装配器读 `<workdir>/overlay_cfg.json` 取字幕 → make_ad 已把 `AD_TMP` 指到 workdir，
  换工程目录时别忘（否则 overlay PNG 落到 /tmp/r2v 互相踩）。

## 3. 15s 转化版结构（含 CTA、不含价格）
0–5s 钩子 → 5–15s 正片 → 结尾 **CTA「点下方小黄车」** + 顶部花字 + 参数条 + 右下「AI生成内容 · 广告」。
价格按用户铁律**不入画面**（价格常变）；但**动作引导必须有**。

## 4. 产品锁新缺口：机头会被画成「比机身宽的大圆盘」（本轮 3/3 全中）
只要分镜里出现「**机头正对镜头 / 侧过机头端详刀网**」，三段**全部**把机头画成宽于机身的大圆盘/蘑菇头
（真机是等径直筒）。**修法已写进共用模板 `templates/product_lock_head.txt`**（所有产品继承）：
【机头与机身·最高优先级】机头直径**与机身直径相同**（相等或略小）…**绝不是比机身更宽的大圆盘、
蘑菇头、飞碟形、喇叭形**；**不要拍"机头正对镜头"的特写**，最多**侧前方 3/4 视角**（同时看得见机身侧面与刀网边缘）。

同批另两条（也已进模板）：
- **别让机器凑近镜头**：钩子镜要写「**拿在胸前、不要高举也不要凑近镜头**」＋「长度不超过画面高六分之一」；
  不写会怼成近景（实测产品占画面高 1/3 ✗）。
- **镜子前的镜头容易正脸朝镜头**（像摆拍）→ 补「侧一点脸、看镜中的自己，不要正脸朝着镜头方向」。

**验收纪律**：改了锁也要**每轮重新放大核**。本轮 h1/h2 一次过，h3 因「凑近镜头＋正脸」再修一轮
（只重跑 h3 单段 = 3 元，然后把 v5/v6 配置里的钩子来源指向新段即可）。

## 5. 成片核验两件工具（本轮新写）
- **钩子归属核对**（防拼错段）：抽 2.0s 帧 → `scale=64:114,format=gray` 灰度 → 与各钩子段同秒帧算
  平均绝对差；最近者必须是期望的那个钩子。实测 **2.1~3.5（正确）vs 60~78（其他）**，区分度极大。
  ⚠️ ffmpeg 输出裸像素**必须加 `-f rawvideo`**（`.raw` 后缀它认不出，报 muxer 错误）。
- **6 格总览图**：每条抽 1s/6s/12s 三帧拼网格 → 一眼看「CTA 字幕 + 参数条 + 合规标在不在、
  有没有价格、产品有没有变形」。
- ⚠️ `xstack` 布局要对**条目列表**截取 n 项，**绝不能对 join 后的字符串做 `[:n]`**
  （n=3 时会截成 `"0_0"` → ffmpeg `Invalid argument` / 写不出文件）。
- R2V `parameters.duration: 5` **可用**（实测 3/3 成功），720P ≈3 元/段。

## 6. 交付
桌面目录用子文件夹（如 `~/Desktop/电商素材/<产品>/视频/15s钩子变体/`），文件名带钩子类型与场景
（`01_冲突_车内_15s.mp4`）；发飞书时逐个 `feishu_send_media.py`（回显 `视频: 0 success` = 成功）。
报告口径：结论先行 + 6 条表格（钩子/场景/大小）+「同场景差异只在开头 5 秒」的说明 +
投放建议（**看 3 秒完播率**判断钩子强弱，砍弱留强，再对留下那条出 5-10 个变体）。
