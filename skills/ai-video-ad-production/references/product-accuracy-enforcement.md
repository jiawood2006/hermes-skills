# 产品准确性强制流程（product accuracy enforcement）

> 2026-09-15 实地教训：用户连续两次判定「产品不准确」。
> 第一次是模型自编产品（改用 r2v 参考图后机身/logo 对了）；**第二次是形制没锁住**
> （参考图=矮胖杯状圆柱+顶部整面金网，生成=细分体+黑色格栅刀头）。
> 本文件 = 在 `references/wan27-r2v-product-lock.md` 基础上补的"必须做"清单，出片前逐条过。

## 0. 出片前先过这四关（缺一关就会返工）

| 关卡 | 做什么 | 产出 |
|---|---|---|
| ① 定型号 | 打开发产品属性表 `产品属性/<型号>.xlsx`（最高优先级资料） | 型号/编码/价格/颜色/重量/官方卖点原文 |
| ② 排除污染图 | 目录里可能混着**别的型号**的图 → 从属性表里的官方素材 URL 下载比对（字节数/哈希一致才算官方原图） | 可放心使用的参考图白名单 |
| ③ 写产品档案 | 形制/比例/刀头/logo/按键位置逐项文字化 | `product-spec-extraction/references/<型号>-spec.md` |
| ④ 形制写进 prompt | 把 ③ 的几何段落整段贴进生成 prompt，**不能只丢参考图** | 见下方"约束段落模板" |

## 1. 为什么参考图不够（实测失败模式）

- 模型会守住**显著特征**（颜色、logo 文字），但**不守几何**：机身长宽比、刀头结构会被"美化"成通用造型
- 实测偏差：矮胖杯状（高≈1.2×直径）→ 细长身材 + 窄颈；整面金色金属网 → 黑色格栅刀头
- 正确做法：**图片给同一性，文字给形制**，两者一起给

### 约束段落模板（整段贴进 prompt，勿省略）
```
图1是一把迷你电动剃须刀（海尔 HSQ1）：矮胖杯状圆柱机身，高度约为直径的1.25倍，灰黑色磨砂金属质感；
顶部整个端面为金色金属网刀头（网面直径接近机身宽度），网面下方有一圈黑色环带；
机身侧面下半部印白色小写"Haier"字样；另一端面有圆形电源键和Type-C充电口。
视频中出现的剃须刀必须与图1的造型、比例、网面颜色、logo 完全一致，不得改变外观或替换为其它型号。
```

## 2. 验收必须"并排质检"，不能自己看一眼说像

```bash
# 参考图 + 成片抽帧 → 拼横向对比图
ffmpeg -y -i ref.jpg -i p3_2.0.jpg -i p3_5.0.jpg -i p2_6.0.jpg \
  -filter_complex "[0:v]scale=-1:640[a];[1:v]scale=-1:640[b];[2:v]scale=-1:640[c];[3:v]scale=-1:640[d];[a][b][c][d]hstack=4" \
  -frames:v 1 compare.jpg
```
→ 交 `vision_analyze`，按五项逐条问："①形制比例 ②颜色材质 ③刀头形状与颜色 ④logo 有无/位置 ⑤按键/接口"，
输出"像 / 不像"。**「有点像」按不像处理**，不要自我说服。

## 3. 上线前的上游四层（本次暴露的缺口，用户明确点名要优化）

| 层 | 现状 | 说明 |
|---|---|---|
| 产品解析 | ✅ 有技能 `product-spec-extraction` | 资料优先级链、图片版 PDF 必读、卖点表带来源；**第一步永远是属性表定型号** |
| 脚本设计 | 🟡 半个：`video-composer-v4` 阶段1-2（信息流式）+ 本技能（剧情3段结构） | 缺**剧情短剧**方法：钩子公式、冲突设计、口播节奏 |
| 受众群体分析 | ❌ 无技能 | 相关碎片只在 `product-composer`（"卖给谁"一句）、`kuaishou-ecommerce-ops`（投放侧） |
| 人物设定 | ❌ 无技能 | `novel-character-agent` 是小说用的，不适用带货短剧角色 |

**纪律**：这三层缺口不要临场编方法糊过去，也不要声称已有成熟流程——先按已知事实交付，
并把缺口写进交付说明（用户已知情，2026-09-15 明确要求"这些都需要优化"）。
