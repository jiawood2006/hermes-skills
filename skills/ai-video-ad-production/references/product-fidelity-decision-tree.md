# 产品保真度决策树 + 形制权威数据（2026-09-15 定案）

> ⚠️ **本文件修正** `references/product-accuracy-enforcement.md` 里"矮胖杯状、高≈1.2×直径"的**错误形制**——
> 那是目测误记，据此写 prompt 直接导致连续返工。以本文件为准。

## 1. 权威形制（HSQ1-2218升级版）

| 项 | 值 | 来源 |
|---|---|---|
| 尺寸 | **74×39×39mm → 高:宽 = 1.93:1「修长圆柱」** | 用户提供的《制作前资料》+ 官方拉页图-13；官方图像素实测 1.93:1 复核一致 |
| 净重 / 机身 | 70g / 黑色哑光缎面 / 圆形单刀头 / 正面 **Haier** 字样（只有一个） | 同上 |
| 刀头 | 顶部平坦端面整面金色金属网（镀钛蜂巢网）+ 网下**黑色窄环带** | 同上 |
| 另一断面 | 圆形电源键 + Type-C 充电口（**不要**拿它当参考图） | 同上 |

**铁律：几何必须由官方尺寸算，禁止目测。** 参考图必须**两张同为竖立视角**——
实测事故：第二张参考图是底面断面圆视图（主体比 0.94:1），模型把"修长"和"圆胖"平均 → 生成矮胖产品。

## 2. 决策树：先判断"能不能交给 AI"，再写 prompt

起手：官方产品图 vs AI 成片抽帧并排看。形制/比例/颜色对不上 → **重 roll 不会变好**。

实测记录（同一产品 4 轮）：t2v 纯文字 → 形制错；加参考图 → 仍错；wan2.7-r2v 写死形制 → 用户"90%准确"
（**回看其实是矮胖罐状，只是乍看像**）；wan2.6-r2v-flash + 正确参考图 + 负面词 → 仍"矮胖罐状 / 锥形杆+网头 / 电子烟状"。
→ **结论：这款产品的形制超出当前 AI 视频模型能力（模型对该品类先验=杯状/罐状），不是 prompt 问题。**

| 保真要求 | 路线 | 成本 |
|---|---|---|
| 产品必须 1:1 像真机 | **官方物料成片** → `scripts/compose_official_material_ad.py` | 0（只烧配音） |
| 要真人剧情、产品不做特写 | AI 人物镜头（产品不出正面/不给特写）+ 官方物料段夹中间 | 低 |
| 真人 + 真机都 100% | 真机补拍 2-3 秒特写插入 AI 剧情（**选项之一，不是"只能实拍"**） | 需拍摄 |
| 想再逼 AI 一次 | wan2.7-r2v **`first_frame` 首帧控制**：首帧给官方真机图，模型在真机上做动效 | 按秒计费 |

## 3. 官方物料成片的四条技法（脚本已实现）

1. 官方拉页图用**模糊填充**（`scale=increase,crop,boxblur` 作底 + `scale=decrease` 原图 overlay）→ **不裁掉官方文案**
2. 字幕**下沉 + 半透明底条**（BorderStyle=3 / &H78000000 / 小 MarginV）→ 不压官方文字
3. 段长 = **配音实测时长 + 0.9s**（ffprobe 测，别写死 4s）
4. 官方文案本身就是卖点 → **不要再叠一层花字**；只补末段 CTA + 右下「官方物料·广告」标注

**ffmpeg 三个坑（改脚本必看）**：音频输入（anullsrc/配音/BGM）放前面、视频片段放后面，否则
`Stream specifier ':a' matches no streams`；混音必须加 `-t 总时长`（BGM 是整首歌，amix 默认取最长 → 输出 180s）；
`-loop 1` + zoompan 要 `-t 段长` 限时，`d=int(段长*30)`。

## 4. 交付前强制自检（用户三次判"产品不对"都在交付之后）

```bash
ffmpeg -i out.mp4 -vf "fps=1,scale=270:-1,tile=5x2" -frames:v 1 grid.jpg   # 全片网格
```
网格必须与**官方产品图并排**逐帧比：①形制比例 ②颜色材质 ③刀头形状颜色 ④logo 有无/位置 ⑤按键接口。
**「有点像」按不像处理**；只看"整体感觉差不多"就交付 = 会被打回（实测：我按抽帧觉得对了就发 v4，用户回"产品严重失真，还是不行"）。

## 5. 提交失败的读码顺序

- `Arrearage / overdue payment` = **账号欠费或免费额度用尽**（t2v 与 r2v/flash 各有独立免费秒数，跑完即需充值）。
  **不是 prompt/参数问题，不要反复重试** → 如实告知用户需充值，并算清已消耗/剩余秒数。
- `InvalidParameter: please provide reference_video_urls or reference_urls` = 用错模型族入参
  （2.6-r2v-flash 要 `reference_urls` + `characterN`；2.7-r2v 要 `media` + `图N`）→ 见 `references/wan-r2v-two-flavors.md`。
