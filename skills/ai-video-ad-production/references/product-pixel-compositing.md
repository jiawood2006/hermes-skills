# 产品像素纪律 + 合成式产品卡（2026-09-16 定型 · 最高优先）

> 用户原话：「产品很多细节都失真严重，越做越差，什么原因」；「水洗时 haier 标识乱了」。
> 本文是**产品保真的最终解法**。SKILL.md 里"产品特写用官方图做 Ken Burns 推近"那条已作废，
> 与本文件冲突时**以本文件为准**。

## 一、为什么"越做越差"（可复现的证据）

| 画面来源 | 金色刀网细节保留 | Haier 标识 |
|---|---|---|
| 官方原图（= 交给 AI 的首帧） | 100%（细密编织网孔 + 锐利金环） | 完整清晰 |
| AI 输出第 0 帧 | ≈70%（网孔变软） | 完整 |
| AI 输出第 110 帧（5 秒内） | ≈30~40%（退化成几条粗同心环） | 崩成「H●+乱符号」 |

**根因**：生成式视频模型是**逐帧重画**，不是搬运像素 → 产品细节按帧单调衰减；
每多跑一道 AI 工序（首帧法 → 产品贴回 wan2.7-videoedit → 再合成）就**再重画一遍**，细节被反复碾压。
**与模型（可灵/万相/Vidu/PixVerse）、提示词、负面词无关**——换模型救不了。

**三级演进（前两级都被用户否过，不要回头）**：
1. ❌ 官方图 Ken Burns / zoompan 缓慢推近 → 用户判「**把贴图运动起来**」
2. ❌ AI 首帧法（官方照片当第一帧）+ 官方产品贴回视频编辑 → 用户判「**细节都失真严重，越做越差**」
3. ✅ **产品像素永不经过 AI**：官方图抠透明 PNG → 非生成式合成；**AI 只负责"人 / 场景 / 气氛"**

## 二、分工铁律

| 交给 AI 生成 | 只走本地合成（0 元、像素级保真） |
|---|---|
| 真人男主 + 真实环境（车内/电梯间/酒店/洗手台） | 产品本身（官方抠图 PNG） |
| 人物的动作与表情、运镜 | 参数 / 价格 / 尺寸标注（PIL 直画，矢量清晰） |
| 场景真实运动（作为卡片的虚化底） | 花字 / 贴片 / 字幕 |

- **剧情镜头里不出现产品**（手部只做"摸下巴 / 整理领口 / 收拾行李"）→ 从源头断掉"AI 画产品"。
- **产品只以合成卡出现**：卡片背景取 AI 镜头的**重虚化版**（`gblur=sigma=22`）——虚化同时把 AI 画错的产品抹掉 ✓。

## 三、合成卡配方（可直接复用）

脚本：`scripts/cutout_product.py`（官方白底图 → 透明 PNG）+ `scripts/make_comp_cards.py`（卡片生成器）。

| 卡型 | 特效 | 用途 |
|---|---|---|
| `hero` 产品卡 | 缓慢放大 0.95→1.0 + 正弦浮动 + **斜向高光扫过**（白色梯形 masked 于产品 alpha）+ 接触阴影 | 产品主视觉 |
| `wash` 水洗卡 | 产品 alpha 区域内叠**竖直水膜**（9 条，170ms 相位差）+ 22 颗**下落水珠** | 全身水洗 |
| `charge` 充电卡 | 二次曲线**线缆**（60 个圆点）+ 产品底部**呼吸灯**（`sin(t*4)` 调 alpha） | 续航/充电 |
| `spec` 参数卡 | hero 特效 + **¥169 弹入**（0.62→1.06 过冲）+ 底部**半透明参数条** | 卖点 + 价格 |
| 尾卡 | 参数卡截 1.7s | 收尾喊价 |

关键几何（1080×1920，实测无裁切）：产品宽 `pw=640`（高 ≈1234）、`ycenter≈960`；
价格 y≈232（顶部暗区）、参数条 y 1655~1745、字幕 y 1560、角标 y 150。
卡片内已画角标 → 主流水线**不要再叠一次** `corner()`。

## 四、成片结构（实拍交付版）

- **15s（14.96s）**：车内心焦(AI) → 产品卡 → 照镜微笑(AI) → 参数卡¥169 → 水洗卡 → 电梯间CTA(AI)
- **30s（29.8s）**：上述 15s（含末尾 CTA）+ 充电卡 → 酒店行李(AI) → 产品卡 → 参数卡 → 电梯间CTA → 价格尾卡

## 五、踩坑清单（都踩过，按此避开）

1. **ffmpeg 解帧默认从 `_0001` 开始** → 脚本按 `_0000` 读会 FileNotFound ✗ → 加 `-start_number 0`。
2. **PIL `Image.alpha_composite` 尺寸必须一致** → `Image.composite(p, new(p.size), ...)` 再与整幅合成会报
   `ValueError: images do not match` → 直接 `bg.alpha_composite(p, (px, py))`。
3. **任务跟踪 JSON 要合并不要覆盖**：`json.dump({tag: tid})` 覆盖写会丢掉上一个任务 id（丢过一次）；
   补救=按已知 task_id 用 `fetch_one.py` 单取。提交脚本一律 `d.update(ids)`。
4. **ffmpeg `vstack/hstack` 输入尺寸不一致会 SIGSEGV(139)** → 拼图统一改用 PIL。
5. **`fps=N,tile=5x3` 有时只出一帧/大量黑格** → 改为按**显式时间点**逐帧抽图 + PIL 网格拼接。
6. **edge-tts 偶发 `NoAudioReceived`** → 包一层重试循环；⚠️ 失败那一次会留下**损坏 mp3**，
   之后 ffmpeg 读它会在音频步骤**长时间空转卡住**（表现为日志不动、m4a 持续变大且无 moov）
   → 每次生成后立刻 `ffprobe` 验时长，为空/报错就重新生成再进流水线。
7. **贴片/字幕绝不压脸、不压产品**：爆炸贴纸放 y≈330（头顶上方）；曾放 y≈600 正好糊住人脸 ✗；
   高亮胶囊避开产品主体区（如放 y≈1420 只压机身下半）。
8. **30s 拼装要把 15s 的末尾 CTA 镜算进前半段**，否则总长只有 28s（踩过）；
   出片后必须 `ffprobe` 核总时长。
9. **同镜头不同区间质量差异**：用 `-ss` 取后段（如"四处张望→微笑"取笑的那段）。
10. 只要 AI 生成过的产品像素进片，用户一眼能看出与前后的官方形态冲突 → 一张都不能留。

## 六、验收（每次必做）

```bash
# 1) 真运动：静止区间必须为 0
ffmpeg -hide_banner -i OUT.mp4 -vf freezedetect=n=-60dB:d=0.8 -map 0:v -f null - 2>&1 | grep -c freeze_start
# 2) 产品细节：裁产品区放大 3 帧（官方图并列对比），确认网孔/Haier 清晰无乱码
# 3) 总时长/音轨：ffprobe -show_entries format=duration -show_entries stream=codec_name
```
另：`freezedetect` **测不出"静图+zoompan"**（静止区间照样 0），是否"贴图感"必须靠肉眼/视觉复核。
