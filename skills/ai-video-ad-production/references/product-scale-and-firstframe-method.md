# 产品尺寸失真 & 首帧法（ProductScale / First-Frame Method）

> 2026-09-16 实测确立。用户原话：「产品尺寸严重失真」→ 这是电商视频最致命的问题之一。

## 一、症状与量化判定（不要凭观感）

- 症状：模型生成视频里，产品**被放大 1.5~2 倍**（真机鸡蛋大小 → 画面里握得像个易拉罐）；
  或反向缩成笔形/推子。无论怎么加负面词、加强提示词都无效。
- **量化标准（必须量，不能看）**：用官方真人手持图做基准。
  - HSQ1 基准：真机 74mm × 39mm，握在手心**约占手掌 2/3 宽**，鸡蛋大小。
  - 检出方法：把成片产品区域与官方图同区域放大并排比对，读产品高度 vs 手/手指比例。

## 二、根因（两条，都已证实）

1. **只要让模型"画"产品，它就一定会把主角产品放大** —— 模型把产品当视觉主体。
   加尺寸锚点（"7cm/握在手心/不到手掌2/3"）只能部分缓解，**不能根治**。
2. **让模型同时画人和产品 → 产品必崩**（实测：产品被画成"比人躯干还大的保温杯"）。

## 三、终极解法：官方实拍照片当「首帧」（first_frame）

**原理**：首帧里的产品就是官方真照片的像素 → 尺寸/形态/logo 天然正确，模型只负责让人物动起来。
同时因为首帧是实拍真人 → **顺带解决"AI 磨皮脸"**。

已验证字段（2026-09-16）：

| 模型 | 首帧写法 |
|---|---|
| 可灵 omni | `media:[{"type":"first_frame","url":...}]`（`kling-v3-omni-video-generation`, mode=pro → 1080P） |
| 万相 3.0 | `input.media:[{"type":"first_frame","url":...}]`（模型名 `wan3.0-video`） |

首帧生视频**不需要 aspect_ratio**，按首帧比例出片。

### 素材来源（HSQ1 实例）
- `拉页图-2.jpg`：商务男士侧脸剃须特写（真人肤质）→ 裁 9:16 = 镜头A
- `拉页图-8.jpg`：男士闭眼享受剃须 → 可做镜头B
- `拉页图-12.jpg`：**产品英雄图，自带官方 74mm×39mm 尺寸标注** → 直接做"真实尺寸"证明镜头
- `拉页图-7.jpg`：金色蜂巢刀网微距特写
- 官方**正面图.png** 与拉页图里的产品形态不一致（银灰渐变 vs 哑光黑）→ 两套参考混用必歪，只用一套

### 裁帧要点（踩过的坑）
1. **裁 9:16 比例**：宽/高 = 0.5625（例：750×1559 图 → 裁 570×1029 再缩到 1080×1920）。
2. **必须避开官方宣传文字**（标题/正文/规格），否则 AI 会把文字也"动"起来。
   先找"人物+产品"完全无字的窗口；**不要用色块硬盖**（会产生横向涂抹条纹，比文字更糟）。
3. 裁完 upscale 到 1080×1920（LANCZOS 即可）。
4. 官方图自带的尺寸标注（74mm/39mm）**保留** —— 正好是尺寸可信度的视觉证据。

## 四、15s 交付版结构（可复用模板）

```
镜头A 真人剃须（首帧法）  2.7s  → videoretalk 口型对齐配音
镜头B 产品特写（首帧法）  5.0s
镜头C 产品英雄 + 缓慢推近  4.7s  ← hero_product.jpg + zoompan（0 元，产品像素 100% 保真）
镜头D 片尾卡（产品+卖点+¥169）2.6s
```
- 镜头C 用 `zoompan` 缓慢推近**不要 AI 生成**：微距镜头 AI 一动就毁刀网。
- 片尾卡文字放**顶部/底部留白区**，别压产品（首版压住产品被否）。
- 配音：本地 edge-tts 分段（每段 ≤5s，配 `--rate=+20%`），逐段贴到对应镜头；
  段落时长必须实测（ffprobe），再据此定镜头时长。
- 合成：concat → `adelay` 排时间轴 → `amix` → **必须加 `apad`**，否则音轨短于视频时
  与 `-shortest` 一起会把成片截短（实测 15s 被截成 13.1s）。
- 字幕用 `drawtext`（fontfile=/System/Library/Fonts/PingFang.ttc，避开依赖 fontconfig 的 ass）；
  `enable='between(t\,0.3\,2.6)'` 里的逗号必须转义 `\,`。

## 六、跨镜头尺寸一致性（2026-09-16 用户新反馈：「全身水洗的镜头里产品尺寸和剃须时不一致」）

**症状**：分段生成时每段独立构图 → 模型在"产品感强"的镜头（冲洗/充电）里**自动把产品拍大**，
与"手持贴脸"镜头里的真实小尺寸对不上。HSQ1 实测：剃须镜头产品 ≈55px（≈头高 1/3，符合真机 74mm ✓）；
水洗镜头 ≈170px、**手指合不拢、手掌包不住** → 视觉放大约 **2.5~3 倍** ✗。

**量化检出（必须做，别凭观感）**：抽各镜头帧 → 叠红色网格（`drawgrid=w=36:h=36:t=1:c=red@0.4`）
并排拼图 → 读「产品高度 ÷ 同一个人的手/头」比值。真机基准：74mm ≈ 头高的 1/3、≈ 手指宽的 3.9 倍。

**根治写法**（在数值锚点之外，下面三条都要加）：
1. **物理可容性**：「握着时**手掌能整个包住机身、五指能合拢绕过机身背面**，机身只比他一根手指粗一点」
   —— 模型对"手能不能握住"远比对数値敏感。
2. **构图约束**：「**中景，不要产品特写**；产品只占画面很小一部分，绝不能占满画面」；
   负面词：「不能变成保温杯/易拉罐/音箱大小；产品不能比手掌大；手指必须能合拢握住机身」。
3. 同段 prompt 里既写远景又写特写 → 特写镜头仍会被放大；**特写镜头要单独出一段**，别和远景混在一条 prompt 里。
