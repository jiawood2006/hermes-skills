# 产品结构保真：接口/按键位置必须从官方图核对（2026-09-16 用户纠正）

## 结论
AI 会把产品的**结构性细节按常识乱放** —— 即使外观、颜色、logo 都已经对了。
实测：HSQ1 迷你剃须刀真机 **Type-C 充电口在机身底部端面**（与电源键同一面、旁边一个小指示灯），
我却让模型把充电线插在**机身侧面** ✗ → 用户直接指出「真机是底部有 type-C 充电口，不是侧面」。

## 做法
1. **先查官方素材，别猜**：本项目 = `~/Desktop/电商素材/剃须刀/产品图/`（右侧图 / 左侧图 / 3.png / 4.png）
   + `拉页图/拉页图-0..13`；HSQ1 的底部端面图 = **`产品图/3.png`**（能看到电源键 + Type-C 槽 + 指示灯）
2. 拼网格逐张看图确认：刀头朝哪端、接口在哪一面、按键/指示灯位置、**侧面是否开孔**
3. **写进 prompt 写死**，正反两面都写：
   > 结构约束：Type-C 充电口在【机身底部端面】（与电源键同一面），机身左右两侧光滑、绝对没有充电口或任何开孔。
4. 充电镜头还要给**朝向条件**，否则模型会把"底部"含糊成"端头附近"：
   > 剃须刀【侧躺在柜面上、底部端面朝向镜头】，Type-C 线从底部充电口接入，底部指示灯亮起蓝色微光
5. 验收：抽充电帧放大，确认线进的是端面不是侧面（`-ss` 抽帧 + `crop` 放大肉眼核）

## 通用清单（每款产品都过一遍）
- 接口位置与朝向（充电口 / 按键 / 指示灯在哪一面，侧面有没有开孔）
- 拆装结构（刀头、网罩是否可拆、怎么拆）
- 官方尺寸 → 高:宽比例（**写进 prompt，不许目测**）
- 材质/表面（哑光 / 亮面）、logo 印在机身的哪个位置
- 参考图"同向同形态"（禁止混入俯视 / 仰视 / 断面图当参考）
