> 起手就用 R2V 多参考图，**不要**先去做抠图合成 / 官方物料拼接 / 产品贴回 ——

## 1. 为什么：把"产品身份"交给参考图，而不是提示词或后期

- t2v 纯文字：模型按品类先验画（迷你剃须刀 → 细长笔形/杯状/电子烟状）✗
- 单张参考图 + 负面词：仍在多张冲突先验里摇摆 ✗
- **产品图 + 人物图两张 reference_image 一起给**：模型把产品**在场景里生成**，
  透视/握持/光影天然融合（不是贴图、不是合成），外观跟随参考图 ✓✓

## 2. 请求骨架（实测可用，2026-09-16）

```python
body = {
  "model": "wan2.7-r2v",                      # 备选 wan2.6-r2v-flash（更便宜，需 audio 参数）
  "input": {
    "prompt": PROMPT,                          # 见下：图1=产品 图2=人物 + 分镜 + 引号台词
    "media": [
      {"type": "reference_image", "url": PROD_URL},   # 官方产品图（拍平 JPG！不能 rgba 透明 PNG）
      {"type": "reference_image", "url": MAN_URL},    # 真人参考图（官方物料里的真人，别用 AI 磨皮图）
    ]},
  "parameters": {"resolution": "720P", "ratio": "9:16", "duration": 10,
                 "prompt_extend": False, "watermark": False},
}
# POST https://dashscope.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis
# Headers: Authorization: Bearer $KEY / Content-Type: application/json / X-DashScope-Async: enable
# 轮询 GET https://dashscope.aliyuncs.com/api/v1/tasks/<task_id> → output.video_url
```
- 参考图必须是**公网 URL** 且 200；透明 PNG 要先拍平：
  `ffmpeg -y -i 正面图.png -vf "scale=1400:-1,format=rgb24" -q:v 2 hsq1_ref.jpg`
- 每张参考图**只放一个主体**（人物图里若带产品，把产品裁掉，否则两组先验互相污染）。
- 参考图必须是**同向同视角**（同一产品的正/侧两张即可；**断面/俯视图会拉平形制**）。

## 3. Prompt 骨架（照抄结构）

```
写实风格广告片，竖屏手机拍摄质感，自然光，真实皮肤质感，电影感浅景深。
图1是一台迷你剃须刀：深灰色金属圆柱机身，顶部黑色环带内嵌浅金色镀钛网状刀网
（网面细腻清晰，浅金色，不能是黑色、不能是金盘或放射状图案），机身正面下方印有 Haier 字样；
这件产品非常小：长约7厘米、直径约4厘米，握在手心里只占手掌的三分之二宽，比拳头还小，
严格按这个尺寸，绝不要放大成杯子、保温杯或罐子。
图2是男主角，请严格保持他的五官、发型、胡须与深色西装造型一致。
第1个镜头[0-4秒]：……（动作 + 镜头运动）；他说：“台词一。”
第2个镜头[4-7秒]：……
第3个镜头[7-10秒]：……
画面中不要出现任何文字、字幕、水印、logo。
```
- **尺寸锚点必写**（手掌占比/比拳头小）→ 否则产品被放大成杯子。
- **刀网颜色必写**（浅金色、不能黑）→ 实测参考图金色会被画成偏黑。
- **台词写在引号里** → 模型自带人声 + 口型（wan2.7-r2v 默认有声），省掉 videoretalk 一道工序；
  但音色不受控（要固定音色用 reference_voice 或后期自己配音）。

## 4. 生产节奏与成本

1. **先跑 5s / 720P 验证**（≈3 分钟，吃免费额度）→ 抽帧核产品形态/颜色/logo/尺寸。
2. 通过后按 3 段 × 10s = 30s 正片放量（可并行提交）。
3. 价格：720P 0.6 元/秒、1080P 1 元/秒；**每个 r2v 模型独立 50 秒免费额度** → 首条 30s ≈ 0 元。
4. 后期：拼接 + 花字/字幕（我方花字放顶部，模型偶发自带底部字幕）+ 右下「AI生成·广告」标注 + BGM。

## 5. 交付前必查（本轮踩过的两个假警报/真缺陷）

- **产品形态**：全片抽帧网格 + 产品区 2 倍放大，和官方图并排比（形态/颜色/刀网/logo/尺寸占比）。
- **运动**：`ffmpeg -i out.mp4 -vf freezedetect=n=-60dB:d=0.8 -map 0:v -f null -` 必须 0 个静止区间。
- **配音落点**：`silencedetect=n=-38dB:d=0.15` 读 silence_start/end **成对**判断每句落在对应镜头内。
  ⚠️ 别把"句中停顿"误读成"句首静音"（edge-tts 句首静音只有 ~0.18s；第一个 silence_end 是**第一句停顿的结束**）。
- **混音装配坑**：`apad` 不带参数 = **无限静音流** → 编码器挂死数分钟、写出十几 MB 无 moov 的文件，
  `-t`/`-shortest` 不必然终止。正解：`apad=pad_dur=0.4` + `-t <总长>` + 把静音视频串作 `-map 0:v -c:v copy` 一步出片。
- **送飞书后回读**：脚本打印 `0 success` 才算送达；微信发大视频会被 iLink 限流静默失败。
