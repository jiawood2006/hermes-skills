# 参考素材纪律 + 后处理管线（贴回 / 配音口型）

> 2026-09-16 实战结论。核心：**产品失真和"AI 脸"大多不是模型不行，而是喂进去的素材/字段不对。**

## 一、参考素材铁律（放参考前逐张放大核对）

### 1. 人物参考必须用"真实拍摄"素材
- AI 生成的磨皮人物图当参考 → 出片**必然是 AI 磨皮脸**（皮肤无毛孔、牙齿假白、发丝塑料光）。
- **提示词压不住**：实测加了「真实摄影质感、皮肤有自然纹理与毛孔、淡妆、牙齿自然不发白、不磨皮」+ 负面「塑料感、过度磨皮、网红脸、假白牙、油光」，输出依旧磨皮。
- **正确来源：翻客户官方物料**。本项目 HSQ1 拉页里就有真人素材：
  - `拉页图-5.jpg` 男士侧脸特写（真实毛孔/胡渣）→ **最佳人物参考**
  - `拉页图-2.jpg` 商务男士全身、`拉页图-8.jpg` 使用场景（仰头闭眼）
  - `拉页图-4.jpg` 四场景小图（车载/商务办公/浪漫约会/出差旅行）→ 场景参考
  - `拉页图-7.jpg` 顶部金网+黑环带结构特写 → 产品结构参考
  - `拉页图-9.jpg` 水洗/刀头 + Haier 产品图；`拉页图-13.jpg` 基本参数（74×39×39mm / 70g / 5V / 5W）
- **检索顺序**：官方拉页/主图/详情页的**真人素材** → 客户自有资产，无版权风险、真实感最好 → 再考虑 AI 生成。

### 2. 参考图集里绝不能混入"形态错误"的图（污染）
- 实测：把一张 AI 图（里面的人手持**齿状梳刀头+细长机身+圆钮**的错误产品）当第 3 张参考喂进去后：
  模型在冲突参考间摇摆 → 万相中景画成"推子"、可灵头顶长成"蘑菇头"、帧间漂移。
- **做法**：人物参考图**必须裁到不含产品**（本项目把 girl 图裁成只有脸+发，去掉手和产品）；
  或干脆不传人物参考图。
- 上传后**回读校验**：`curl -o /dev/null -w '%{http_code}' https://yunvela.com/dh/<file>` 必须 200；再用 vision 确认画面里没有产品/手。

### 3. 产品比例必须来自官方尺寸，且逐帧放大核对
- 尺寸以官方参数为准（HSQ1 = 74×39×39mm → **高:宽 1.93:1**）。
- 交付前**放大逐帧**看，别凭整体观感下结论（本项目两次因为"整体看着还行"误判，被用户纠正：可灵"明显失真"、
  "人物真实感还有欠缺"）。
- 测量法：抽帧后叠 10% 刻度线（青=纵向%、橙=横向%）→ vision 读产品上下沿/左右沿 → 换算像素比。
  ⚠️ 阈值分割自动取外接框时 ROI **不要贴边**，否则会把背景暗部（影棚灯/阴影）框进来，比例全错。
- 各家容易画错的方向：可灵 → 顶部成"凸起金圆盘/蘑菇头"；万相 → 帧间漂移（矮罐↔方柱）、齿状刀头；Vidu → 矮胖罐+小金凸顶。

## 二、产品保真终极方案：产品贴回（视频编辑模型）

模型对精细产品结构的还原有上限（行业常态，别人的样片同样不准）。**职业做法**：人物/场景交 AI，
**产品用官方真图贴回**，得到 100% 保真。

| 模型 | 价格 | 免费额度 | 说明 |
|---|---|---|---|
| `wan2.7-videoedit`（万相2.7-视频编辑） | **0.6 元/秒**（720P） | 50 秒 | 首选，最便宜 |
| `wanx2.1-vace-plus` | 0.70 元/秒（720P） | 50 秒 | 局部替换/主体替换备选 |

文档：`help.aliyun.com/zh/model-studio/wan-video-editing-api-reference`、
`help.aliyun.com/zh/model-studio/wan-video-editing-guide`、`/wanx2-1-vace-plus`
（输出按 720P 计，需要 1080P 时最后整体超分）。

**替代方案（更省，本项目已在用）**：产品特写段直接用官方图做 Ken Burns 动效
（见 SKILL.md「产品特写别交给 AI」+ `scripts/compose_official_material_ad.py`），原配音接上不断句。

## 三、配音 + 口型（用户明确要求"配音需要和口型匹配好"）

**现状语义（别搞错）**：
- **万相** 生成的片子**自带音轨**（aac，环境音/BGM 级）。
- **可灵** 的 `parameters.audio`：`false` 默认；`true` 只是**自动配 BGM/音效**，**不含台词口型**。
- **PixVerse / Vidu** 默认无声（Vidu Q3-Ad 官方宣传有原生音频，实测成片 `ffprobe -select_streams a` 为空）。

**正确管线**：台本 → **我方 edge-tts 配音**（音色/文案完全可控）→ **口型驱动模型**把画面口型对齐到我们的音频 → 叠字幕/花字。

| 口型模型 | 价格 | 免费额度 |
|---|---|---|
| `videoretalk`（声动人像，视频口型替换） | **0.08 元/秒**（5 秒 = 0.4 元） | 1800 秒 |
| `wan2.2-s2v`（数字人，图/视频 + 音频） | 480P 0.5 / 720P 0.9 元/秒（detect 0.004 元/张） | 100 秒 |
| `pixverse/pixverse-lipsync` | 0.12 元/秒 | 无 |

**验收**：`ffprobe -select_streams a` 必须有音轨 + 抽帧看口型是否随台词开合（不能只信参数回执）。

## 四、素材/字段小抄（完整字段见 four-model-video-benchmark.md）
- 万相 3.0 → `input.media:[{"type":"reference_image","url":...}]`，prompt 用「图1/图2」指代（`input.images` 无效）。
- 可灵 → **必须 `kling/kling-v3-omni-video-generation`**（`kling-v3-video-generation` 不支持参考生视频，只能 first_frame），
  `media:[{"type":"refer"}]` + prompt `<<<image_1>>>` + `negative_prompt` 字段。
- PixVerse → `media:[{"type":"image_url","url":...,"ref_name":"剃须刀"}]` + prompt `@剃须刀 ` 绑定。
- Vidu → `media:[{"type":"image","url":...}]` + **`parameters.size:"1080*1920"`**（不传就出横屏 1914×1084）。
