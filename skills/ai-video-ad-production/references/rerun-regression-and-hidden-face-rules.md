## 一、「看不见的面」＝ 模型的自由发挥空间（用户原话：「又是侧面充电」）

**规则写对了 ≠ 不再犯。** 9-16 已经把「Type-C 在底部端面」写进 `product-structure-fidelity.md`，
9-17 仍然复发，根因不是规则本身，而是**朝向没写**：

- 复发经过：v20 把充电镜描述从「**侧躺**在柜面上」改成「他把剃须刀**放在**床头柜上」→
  底部端面**朝下、看不见** → 模型没东西可抄，就在圆柱**侧面**画了一个插口 ✗。
- **判据（可直接推广到任何产品任何细节）**：
  若某细节只存在于某一个面上（充电口 / 按键 / 指示灯 / logo / 拆装缝），而那个面**不朝向镜头**，
  模型**必然自己发明一个可见位置**。这跟"写没写死约束"无关。

**正解三条必须一起上**（v21 三条齐上后一次过 ✓）：
1. **逐镜在镜头描述里写朝向**：「它**侧躺着**：机身水平横放在柜面上、机头朝画面左侧，
   **朝向镜头这一端就是它的底部端面**」——不要在通用约束段写一句就当完成。
2. **把该面的官方特写单独作为一张参考图**喂进去：底部端面 = `产品图/3.png` → 存成 `hsq1_base.jpg`
   当**图4**，HEAD 写明「图4＝底部端面特写（最重要，充电镜必须照这个拍）：端面中间圆形电源键、
   键下方横向 Type-C 插口、旁边小指示灯；充电口**只在这个端面上**」。
   （官方布局已核：电源键同心圆金属键 ＋ 横向 Type-C 槽 ＋ 小指示灯点，同在该端面。）
3. **通用约束 ＋ 尾部重申**都写死反面：「机身的长侧面完全光滑，**没有任何接口、开孔、按键**」。

**反查（不核等于没修）**：该镜抽 3 帧（4.5 / 6.0 / 7.5s）放大 1.5 倍核四项 ——
①侧躺且端面朝镜头 ②线插在**圆端面**上而不是侧面 ③端面能看到电源键＋插口＋蓝灯
④长侧面上**没有**多出来的接口。

## 二、重跑整段会带崩「已经通过」的镜 —— 已通过清单 ＝ 回归清单

**一个 10s 段是一次生成：改任何一句，整段三镜都会重画。** 一天内三连栽：

| 版本 | 只想修 | 顺手带崩的 |
|---|---|---|
| v16 | 加生活情景（用户要求"不要只罗列场景"） | 刀网金色掉成浅金/银白、长径比 2.03 → 1.58 |
| v18 | 换「机头直径当尺子」的比例锚 | 长度没修好（仍 ≈2.4），白花一轮 |
| v20 | 按「显小」标准收小产品 | 充电口从底部端面**跑到侧面**（改动删掉了"侧躺"朝向） |

**纪律**：
1. 重跑前把**该段所有已知约束一次性全写进 HEAD**，别一轮只修一个 —— 每轮 15 分钟 / 6~18 元；
2. 重跑后**该段三镜全部重核**，不能只看这次想修的那一镜；
3. 维护**「已通过清单」当回归清单**，每次重跑逐项过：
   金网金色 / 宽黑环 / 长径比 1.9 / **无侧面接口** / 无胡须 / 眉间不皱 / 不直视镜头 /
   产品占画面 ≤1/6 / 情景有动作链＋表情变化 / 全片无价格；
4. 被带崩的镜**先看能否从上一个通过版本取**（同段内镜头边界 ≈ 3.33s / 6.67s 处切），
   再决定是否整段重跑 —— 别默认整段重来。
