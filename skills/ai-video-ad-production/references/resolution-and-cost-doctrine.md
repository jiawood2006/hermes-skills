# 分辨率与计费口径（2026-09-18 A/B 实测定论）

配套：`references/product-lock-escalation-and-resolution-pitfall.md` §1（第一次撞到"改分辨率打坏产品"）、
`references/bailian-video-model-catalog.md` §七（引擎横评：产品镜改用 `wan3.0-video`）。

用途：用户问 **「测试用 720P 省钱、定稿再改 1080P 行不行？」** 或 **「为什么这么贵？」** 时，直接照本页答。
**先纠正认知，再给方案** —— 不要让用户以为"定稿升 1080"是一步免费升级。

---

## 1) 三个必须一次讲清的事实

**① 成片早就是 1080 了 —— 这一步 0 成本、已经在做。**
实测（ffprobe）：AI 生成源 `720×1280` → 装配器每段 `scale=1080:1920` → 交付成片 `1080×1920`；
字幕/花字/参数条/CTA 全部在 1080 画布上渲染。**"720P 生成 + 1080 交付"就是现状态。**

**② AI 视频换分辨率 ≠ 放大，而是重新抽卡。**
`parameters.resolution` 是**生成参数**，不是导出设置。改 1080P = 同 prompt **重新生成一遍**：
画出来的不是原来那条（机位、景别、人物、产品细节全变），等于全部重做 + 多花钱（1080P ≈ 720P 的 **1.7~2 倍**）。
所以"测试 720 → 定稿原生 1080"是**重做**，不是升级。

**③ 实测原生 1080P 更差**（同 prompt、同 5 张参考图、`wan3.0-video`、5s/9:16）：

| 项 | 720P 生成 → 装配升 1080 | 原生 1080P |
|---|---|---|
| 产品形态 | ✅ 等粗直筒、比例正 | ✗ 机头歪斜变形、几何不对 |
| 刀网 | ✅ 饱和香槟金 + 放射菱形网格 + 宽黑环 | ✗ **2.0s 那一帧变成暗灰黑圆盘（金色丢了）** |
| logo | ✅ 干净 Haier 一次 | ✗ 位置漂移、发软 |
| 锐度 | ✅ 干净利落 | ✗ **并不更锐**，反而更"塑料"、细节更糊 |
| 文件 | 5.7MB | 14.4MB（大 2.5 倍，画质无提升） |
| 构图 | — | ✗ 整条是**另一条片**（机位/景别全变） |

→ **定论（不必再赌）**：**全流程锁 720P 生成**。清晰度靠两条腿：
(a) 装配升 1080（现状，0 元）；(b) **产品特写/刀网用官方真像素素材**（原生 1080 清晰 + 100% 保真 + 近 0 成本）。
**门面镜（0–3s）也不要单独上原生 1080** —— 实测会上崩产品。

## 2) 回复话术模板（结论先行）

> 可以 —— 但你现在拿到的成片**就已经是 1080 了**（720P 生成 + 装配升 1080，0 成本）。
> 而且 AI 视频改 1080P **不是把片子放大，是重新生成一遍**（画面会变、钱 ×1.8）。
> 我实测了一条：原生 1080P 产品反而变形、刀网掉金、并不更锐。
> 所以**锁定 720P 生成**，清晰度用官方真像素素材补。

## 3) 成本口径（用户问"为什么这么贵"）

AI 视频**按秒计费** —— 1 秒 = 24~30 帧逐帧去噪，每帧跑整张大模型。所以成本 = **秒数 × 分辨率**。

| 720P 档 | 元/秒 |
|---|---|
| pixverse-v6-r2v-omni | 0.27（最便宜） |
| **wan3.0-video** | **0.6** |
| kling-v3-omni | 0.6 |
| wan2.7-r2v | 0.6 |
| vidu-q3-ad | 0.78 |
| wan2.1-vace-plus | 0.734 |

1080P ≈ **×1.7~2**；4K ≈ 3 元/秒。参照：25 秒 = 5 次独立生成 ≈ **15 元**；
对比实拍团队一条 15s 通常几千到上万；相对磁力金牛一天几百到几千消耗属零头。

**省钱四招（已落进 make_ad 工作流）**：① 全部 720P；② 全部无声（旁白后期 edge-tts 云希配）；
③ 只用 5 秒档（同一段能拆就拆）；④ **提交失败不计费**（prompt 超限/模型 id 写错这类错误是 0 成本，可以先探测）。

## 4) A/B 归因的做法（别一轮一轮试）

怀疑"分辨率还是 prompt 导致失真"时：**同一 prompt、同参考图、只差一个变量**，两条同时提交，
一次拿到归因（成本 = 一条 5s 的钱）。720P 那版可直接复用已有产物 → 实际只花新生成那一条。
对比只比**同一时段**的帧，并把对比图（全帧 + 产品区 1:1 放大）发给用户看。
