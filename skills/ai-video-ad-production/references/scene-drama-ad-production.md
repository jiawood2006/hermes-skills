# 场景化剧情带货片（Scene-Drama Ad）制作手册

> 2026-09-16 用户纠正后定型的**正确方向**。教训：我曾把"官方产品图做缓慢推近"当成视频，
> 用户判定为 **「这种把贴图运动起来的」** ✗。他要的是**真人男主在真实场景里演剧情**。

## 一、用户要的"场景化"到底是什么

判定标准（用户样片实测）：

| 要素 | 要求 |
|---|---|
| 主体 | **真人质感的男主**（商务造型），不是产品图 |
| 场景 | **真实环境**：车内早高峰 / 电梯间 / 洗手台 / 酒店床头柜 / 登机箱 |
| 剧情 | 有痛点-转折-解决的故事线，**前 3 秒不卖货** |
| 运镜 | 每镜都动（缓慢推近 / 横向平移），无静止画面 |
| 节奏 | 多镜头快切，每镜 **2~3 秒** |
| 字幕 | 口语化短句，居下白字黑描边，与配音逐句对应 |
| 贴片 | 黄色爆炸贴纸 / 白色高亮胶囊 / 红色箭头 / 价格弹入大字 |
| 规格 | 用户样片就是 **15.07s 和 30.07s** 两条（投流简版 + 完整版） |

**样片是唯一验收基准**：用户发的样片抽帧+语音转写曾落在 `/tmp/newsample/`（`doc_*/grid.jpg` + `a.txt`），
必须真读一遍再动手，别凭记忆猜风格。

## 二、可复制的镜头模板（15s 通勤剧情版）

```
1 车里焦急看表（痛点）2.9s   ← 字幕「早上起晚了，胡子都没来得及刮」+ 爆炸贴纸「差点忘了刮」
2 取储物格里的产品   2.8s   ← 「车里常备一个，随手就能补」+ 高亮贴纸「迷你机身·随手一塞」
3 仰头贴脸补剃       2.9s   ← 「八千五百转，几下就干净」+ 高亮「8500转高速马达」
4 照镜抹下巴、自信微笑 2.6s   ← 「见客户前，清爽上线」
5 产品英雄（官方图+AI微动）2.2s ← 「镀钛刀网·充电1小时·续航90天」+ ¥169 弹入
6 电梯间拿着产品+CTA  1.6s   ← 爆炸贴纸「出门带它一个就够」
```
30s 版 = 上述 15s + 后半段卖点场景（水流冲洗 / 床头柜充电 / 登机箱旅行锁 / 产品英雄 / CTA）各 2.6~3.5s。

## 三、人物一致性（关键）

场景镜头必须**同一个演员**，做法：

1. 从客户官方物料里裁一张**纯人物肖像**（无产品、无文字）当"角色参考图"：
   `产品图/拉页图-2.jpg` → crop(120,300,750,940) → 头肩+西装 ✓
2. 上传公网，可灵 omni 传 `media:[{"type":"refer","url":...}]`，提示词开头写：
   > 画面中的人物是图1中的亚洲商务男士，严格保持他的相貌、发型与胡须与深色西装造型一致：<场景+动作>
3. `parameters`: `mode=pro`（1080P）、`aspect_ratio=9:16`、`duration=5`
4. 走官方真人素材做参考，人物不会出现 AI 磨皮脸（实测毛孔、发丝、胡渣细节保留）

## 四之前｜产品像素纪律（2026-09-16 血的教训，最高优先）

**用户原话**：「产品很多细节都失真严重，越做越差，什么原因」；「水洗时 haier 标识乱了」。

**实测证据**（放大逐帧比对，官方原图 vs AI 输出）：
| 位置 | 金色刀网细节保留 | Haier |
|---|---|---|
| 提交给 AI 的首帧（官方像素） | 100%（细密编织网孔 + 锐利金环） | 完整 |
| AI 输出第 0 帧 | ≈70%（网孔变软） | 完整 |
| AI 输出第 110 帧（5s 内） | ≈30~40%（退化成几条粗同心环） | 开始崩→变成「H●+乱符号」 |

**根因（不可绕过）**：生成式视频模型**逐帧重画**，不是搬运像素；产品细节按帧单调衰减。
且每多跑一道 AI 工序（首帧法 → 产品贴回 → 再合成）就**再重画一遍** → 细节被反复碾压 = 「越做越差」。
与模型选择（可灵/万相/Vidu/PixVerse）、提示词、负面词**无关**。

**唯一解 = 产品像素永不经过 AI（非生成式合成）**：
1. 官方图抠透明 PNG（`cutout_product.py`：白底亮度阈值转 alpha，2000px 原图 → 保留网孔/logo 原像素）
2. 产品卡 = 官方 PNG 用 PIL/ffmpeg **只做几何变换**（缩放/位移/轻微浮动）+ 光影扫过 + 接触阴影，
   叠在**真运动的场景视频**上（场景取 AI 生成镜头的重虚化版，虚化同时把 AI 画错的产品抹掉 ✓）
3. 剧情镜头里**产品不出现**（手部只做"摸下巴/整理领口/收拾行李"，避免 AI 画产品）
4. 参数/价格/尺寸标注用 **PIL 直接画**（矢量清晰，不是 AI 生成的字）
5. 产品卡的动效足以满足"有真运动"：背景场景在动 + 产品缩放/浮动 + 高光扫过 + 水流/呼吸灯

**分工铁律**：**AI 只负责"人 / 环境 / 气氛"，产品像素只走合成**。这条同时解决尺寸、形态、logo、网孔四类失真。

## 配音混音装配（2026-09-16 踩坑，照抄即可）

**症状**：`ffmpeg -i a1.mp3 ... -filter_complex "...amix=...,apad[a]" -map [a] -t 15 -c:a aac out.m4a` 挂死 6 分钟、写出 16MB 音频、文件无 moov。

**根因**：`apad` **不带参数 = 无限静音流**，`-t`/`-shortest` 在 filtergraph 出口不必然终止 → 编码器空转。

**正解（一步出片，秒级）**：
```
ffmpeg -loglevel error -y -i 静音视频串.mp4 -i s1.mp3 -i s2.mp3 ... \
  -filter_complex "[1]adelay=150|150[a0];[2]adelay=2620|2620[a1];...;[a0][a1]...amix=inputs=N:normalize=0,afade=t=out:st=<总长-0.7>:d=0.7,apad=pad_dur=0.4[a]" \
  -map 0:v -map "[a]" -t <总长> -shortest -c:v copy -c:a aac -b:a 160k -movflags +faststart 输出.mp4
```
要点：① `apad=pad_dur=0.4`（有限）② 视频串作 `-map 0:v` 并 `-c:v copy`（不重编码）③ 音频序号从 `[1]` 起（0 是视频）④ **别先导 m4a 再 mux**——多一步就多一个挂死点。

## 发布前像素级自检清单（2026-09-16 实战得出，逐项必过）

1. **调 ffprobe**：duration / 1080×1920 / 25fps / h264+aac 齐全。
2. **freezedetect**：`-vf freezedetect=n=-60dB:d=0.8` 数 freeze_start，必须为 0。
3. **语音落点**：`silencedetect=n=-38dB:d=0.15` 读 silence_start/end 成对 → 每句台词的语音区间必须落在**对应镜头内**（⚠️ 别把"句中停顿"误读成"句首静音"，edge-tts 句首静音只有 ~0.18s，正常）。
4. **像素级放大**：把**交付文件**（不是中间素材）按镜头裁产品区放大 2 倍看图 → 金网有编织细节（不是色块/粗环）、Haier 字母无乱码。
5. **贴片遮挡**：highlight 胶囊 / 贴纸**不得盖住 Haier 或刀网**（合成卡里 Haier 在机身底部，胶囊放 y≈250 顶部区才安全）。
6. **文字不压产品**：¥169 与顶部角标至少留 70px，且不得压产品顶边。
7. **合成特效边界**：PIL 画的"水流/光扫"必须 `GaussianBlur(3~32)` 软化，否则出硬边白条，一眼假。
8. **音轨**：volumedetect mean ≈ -20~-26dB、max < -1dB（不削波）。

## 四、产品保真：场景镜头必须"贴回"（历史方案 · 已降级）

**实测**：AI 在场景里画的产品一律不准（细管状 / 扁平矩形 / 口红色 / 罐子），
加提示词也压不住 ✗。唯一可靠解 = **产品贴回**（`wan2.7-videoedit`）：

```json
{"model":"wan2.7-videoedit",
 "input":{"prompt":"把视频里男士手中和下颌处的剃须刀，替换成参考图1 中的剃须刀：严格保持参考图1 的形状、比例、颜色、材质与 logo 一致；产品的位置、大小、朝向、运动跟随原视频，不要改变产品的尺寸，不要放大产品。画面其余内容保持不变，不要添加任何文字。",
          "media":[{"type":"video","url":"<场景镜头公网URL>"},
                   {"type":"reference_image","url":"<官方产品图公网URL>"}]},
 "parameters":{"resolution":"1080P","prompt_extend":false,"watermark":false}}
```
- 价 **0.6 元/秒**；输出 1080P ✓（比早前记录的 720P 更好）
- 实测：替换后产品形态/尺寸/logo 正确，**帧间一致**，握持手指边缘融合自然 ✓
- 参考图用官方**正面图.png**（银灰渐变机身+黑环+金网+Haier）→ 贴回后产品颜色随之统一

## 五、花字 / 贴片 / 字幕（本地 PIL，0 元，可控）

`overlay_anim.py` / `build_ad.py` 里的做法：把镜头解成 PNG 帧 → PIL 逐帧画 → 再编码。
比 ffmpeg drawtext 可控得多（能画多边形爆炸贴纸、圆角胶囊、逐帧缩放弹入）。

```python
# 黄色爆炸贴纸（24 角星形）+ 黑字
# 白色圆角胶囊 + 黄色描边 + 深色字（高亮贴片）
# ¥169 大字：scale = 0.6 + 0.45*ease_out(t)，带过冲
# 常驻角标：右上「海尔 · 迷你便携剃须刀」（只在产品相关镜头显示）
```
字体：`/System/Library/Fonts/PingFang.ttc`（`ImageFont.truetype(PING, size, index=1)` 取粗体）✓ 中文正常。

## 六、踩坑清单

1. **不要把静图推近当镜头**（用户原话「把贴图运动起来」）→ 产品镜头也要 AI i2v 出真运动。
2. **官方宣传图上的文字会被 AI 一起"动"起来** → 裁剪时避开；用色块硬盖会产生横向涂抹条纹（更糟）。
3. **`-ss` 取偏移**：同一镜前后段质量不同（如"四处张望→微笑"），取表情更好的后段。
4. **任务跟踪文件要合并不要覆盖**：`json.dump({tag:tid})` 覆盖写会丢上一个任务的 id（我丢过一次，
   只能按 task_id 手动 `fetch_one.py` 取回）。
5. **合成音轨必须 `apad`**：否则配音短于画面时与 `-shortest` 一起把成片截短。
6. 贴回后的镜头才进成片；未贴回的镜头里产品形态会与前后的官方形态冲突（用户一眼看出）。
