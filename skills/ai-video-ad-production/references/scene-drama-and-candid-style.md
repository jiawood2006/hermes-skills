# 场景化剧情片 · 真实感抓拍 · 全运动镜头 · 分镜措辞（总纲）

> **这篇管什么**：① 场景化剧情带货片怎么做（判定标准、镜头模板、人物一致性、产品入镜路线）；② "人物不真实/太假"怎么治（旁白＋抓拍拍法）；③ 全运动镜头铁律（禁静图/贴图）；④ 分镜正文（`project.json → segments`）措辞规则；⑤ 已作废路线留档。
> **什么时候读**：要拍/改场景化剧情片；用户说「又成贴图了」「人物不真实，太假」「像PPT / 图片拼接」「产品太小 / 认不出是什么」，或要求"照样片标准"时，**先读本文再动手**。
> **最新口径优先**：产品镜终极解 = **官方真像素插入镜**（`scripts/build_official_product_insert.py`），AI 只做人物/生活场景镜；旁白＋抓拍（**全程无人直视镜头、不对口型**）；视频里**不放价格**。

## 一、场景化剧情片：权威口径与判定标准

### 1.1 权威口径（最高优先级）

用户 2026-09-16 纠偏原话：**「我需要的是场景化的，不是这种把贴图运动起来的，样片不是给你看过」**；同日另一句：**「这种又成贴图了」**、**「我不要这种贴图的」**。

- ✅ 交付形态 = **AI 生成的「真人 + 真实环境 + 剧情动作 + 运镜」多镜头片**
- ❌ 「官方静图 + 运镜 / 整片用官方图当首帧」= 用户判定**「把贴图运动起来」**（本项目 v1、v2 连续两次被判废）
- 官方真图只承担：**产品特写插镜**（现行 = 官方真像素插入镜，见 §1.5）、**片尾价格卡**（⚠️ 价格卡已于 2026-09-17 作废，见 §五）
- 产品识别一律靠**真品镜头**（官方真像素插入镜 / 贴回后的真品镜头），不靠 AI 画

### 1.2 判定标准（用户样片实测）

| 要素 | 要求 |
|---|---|
| 主体 | **真人质感的男主**（商务造型），不是产品图 |
| 场景 | **真实环境**：车内早高峰 / 电梯间 / 洗手台 / 酒店床头柜 / 登机箱 |
| 剧情 | 有痛点-转折-解决的故事线，**前 3 秒不卖货** |
| 运镜 | 每镜都动（缓慢推近 / 横向平移），无静止画面 |
| 节奏 | 多镜头快切，每镜 **2~3 秒** |
| 字幕 | 口语化短句，居下白字黑描边，与配音逐句对应 |
| 贴片 | 黄色爆炸贴纸 / 白色高亮胶囊 / 红色箭头 / 价格弹入大字 |
| 规格 | 用户样片就是 **15.07s 和 30.07s** 两条（投流简版 + 完整版） |

**样片是唯一验收基准**：用户发的样片抽帧+语音转写曾落在 `/tmp/newsample/`（`doc_*/grid.jpg` + `a.txt`），必须真读一遍再动手，别凭记忆猜风格。

### 1.3 开工第一步：把用户的"样片"挖成规格表（禁凭记忆）

样片（微信/飞书传来的视频）落盘后目录形如 `/tmp/newsample/doc_*_video/`，内含：

| 文件 | 用途 |
|---|---|
| `a.wav` | `ffprobe` 量时长 = **交付规格**（实测两条样片 = 15.07s / 30.07s → 正好对应"15s / 30s 两种规格"） |
| `a.txt` | 样片台词 STT 全文 → 反推**叙事结构**（痛点 → 场景 → 产品 → 使用 → 结果 → 价格/CTA） |
| `grid.jpg` | 抽帧网格 → 反推**镜头数、场景、字幕位置与句式、贴片动效样式、运镜** |

> ⚠️ 样片里听来的说法**不得当话术**：官方物料没有的词一律不用（HSQ1 实测：样片说"鸡蛋大小"，官方无此卖点 → 禁用）。

### 1.5 产品入镜路线

**路线铁律：只要"贴上去"，用户就判贴图。**

| 做法 | 结果 |
|---|---|
| 官方图抠图 → 叠到 AI 背景上（合成卡） | ❌ 用户一眼识破。查过 alpha：残留半透明像素铺满整幅矩形，但**修干净也没用** |
| AI 出人/场景 + 产品卡贴片按时间轴拼 | ❌ 同上 |
| 官方产品图 Ken Burns 缓慢推近当产品镜头 | ❌ 同上（旧方案，已在 SKILL.md 标注废弃） |

**根因**：产品像素不是**该场景渲染出来的** —— 光影方向、透视、手部接触关系必然不自洽。修 alpha / 加阴影颗粒只是"更不容易被发现"，不是解决。

**正解（当前主线）= r2v 多参考图**：`wan2.7-r2v`，`media` 里同时给
`{type: reference_image, url: 官方产品图}` + `{type: reference_image, url: 人物图}`，
prompt 用「图1 / 图2」指代。产品身份由参考图锁定，模型**在场景里把它画出来**：
手持、贴脸补剃、水龙头下冲洗、插线充电、塞进旅行包 —— 全部光影自洽。

- 用户验收口径：**「产品细节基本满足了」**（即：接受 AI 固有轻微漂移，换取"无贴图感"）；用户原话确认过代价：「代价：产品细节是AI画的，会轻微漂移」。
- 先跑 5s/720P 验证（每模型 50 秒免费额度），通过了再放量到 3 段 ×10s。

**产品镜的终极解（2026-09-19 定稿）= 官方真像素插入镜**，脚本 `scripts/build_official_product_insert.py`：

- 触发条件（满足任一即换路线，不要再改 prompt）：中景手持镜的产品形态**反复修不好**（本项目：两轮各换一种错法 —— 先"没有刀头的光筒"，后"保温杯"）；用户说"认不出是什么 / 不像真机 / 产品太小 / 刀网不对"，且已按锁改过 2 轮；投放素材要求"产品必须真实"（甲方红线）。
- 铁律依据：用户定的"**同缺陷改 prompt 修 2 次不根治 → 停手换路线/换引擎**"。**AI 生成的产品只适合"生活情景里的道具"，产品必须被认出来的镜头交给真像素。**
- 片内结构（15s 变体）：`[钩子 5s（AI，人物/情绪）] + [官方真机产品镜 3s（真像素，零 API 成本）] + [正片 7s（AI，截短）] = 15s`；官方镜放 **5~8s**，**不要**放片尾（会和 CTA/参数条抢注意力）。
- 做法 = 三个真像素特写各 1s，缓慢推近（`zoompan z='min(zoom+0.0006,1.06)'`），之间 0.15s 交叉溶解：

| 镜 | 素材 | 处理 |
|---|---|---|
| 1 | `拉页图/拉页图-7.jpg` | **裁掉左侧中文文案与底部标注**（本项目用 `crop(118,480,556,1105)`）；只留金网+深灰底 |
| 2 | `产品图/正面图_cropped.png` | **白底必须抠成透明**（否则贴上深灰底会露出白色矩形 ✗）；合成到深灰径向渐变底，产品占宽 ~0.62 |
| 3 | `产品图/3.png` | 先自动求**非白内容包围盒**定位端面，再按 9:16 裁 + 抠白底；展示电源键＋Type-C |

- 三个必踩的坑：① 白底不抠 → 露出矩形（像素级把接近纯白区域置透明、边缘按阈值羽化）；② 官方图带中文文案/标注 → 裁图必须避开（否则成片出现半截字 ✗）；③ 插入段必须带一条静音音轨（装配器按段取音频流，无音轨会报错 ✗）：`ffmpeg -i official.mp4 -f lavfi -i anullsrc=channel_layout=stereo:sample_rate=44100 -shortest -c:v copy -c:a aac`
- 时间轴：插入 3s 后**所有 overlay 时间整体 +3s**。规则：`start ≥ 5.0s` 的字幕/花字 → `start = min(start+3, 13.0)`、`end = min(end+3, 14.9)`；参数条锚到 `12.6~14.9`；CTA 落在末尾 1.5~2s 内。旁白不用手工重做（装配器按字幕 `start` 自动重排对齐）。官方段配一句**官方原文**旁白（本项目用「全新镀钛刀网，持久耐用更锋利。」），否则 5~8s 出现 1s+ 无语音空白。
- 核验：抽帧必须含官方段（`2s` 钩子 / `6.5s` 官方产品镜 / `13s` CTA＋参数条）；官方段看产品是否完整（金网球面＋黑环＋机身＋Haier）、**有没有白色矩形残留**；`ffprobe` 时长必须 **15.000s 整**、1080×1920。
- 成本：官方插入镜 **0 元**、重装配 6 条变体 **0 元** → "AI 画不像"时换真像素路线的**边际成本是 0**，没理由继续重 roll 抽卡。

### 1.6 产品结构事实纪律（写 prompt 前必查）

2026-09-16 用户纠正：**「真机是底部有 Type-C 充电口，不是侧面，你设计的不是」**。

- HSQ1 实际结构：**Type-C 充电口在【机身底部端面】**，与**电源键同一面**，旁边有小指示灯；**左右侧面是光滑的、没有任何接口或开孔**。
- 官方图指认：`~/Desktop/电商素材/剃须刀/产品图/3.png` = 底部端面特写，一眼可见电源键 + Type-C 槽 + 指示灯。
- 做法：① 打开官方图逐条答完（接口在哪一面？按键在哪一面？哪一面是刀头？哪一面有 logo？侧面/背面有没有开孔？）；② prompt 正反两面都写死：`Type-C 充电口在【机身底部端面】（与电源键同一面），机身左右两侧光滑、绝对没有充电口或任何开孔。`；③ 充电镜头：`剃须刀【侧躺在柜面上、底部端面朝向镜头】，线从【底部充电口】接入，底部指示灯亮起蓝光`；④ 生成后放大抽帧复核。
- r2v prompt 里必须写死的两条（不写就漂）：机身形态与 logo 措辞 —— 现行锁口径见 §四.0。

### 1.7 人物一致性（同一男主贯穿全片）

1. 从客户官方物料里裁一张**纯人物肖像**（无产品、无文字）当"角色参考图"：`产品图/拉页图-2.jpg` → `crop(120,300,750,940)` → 头肩+西装 ✓；裁完 scp 到 `yunvela.com/dh/`
2. 每次生成都带 `media:[{"type":"refer","url":"<人物参考图>"}]`，prompt 开头固定写：

> 画面中的人物是图1中的亚洲商务男士，严格保持他的相貌、发型与胡须与深色西装造型一致：<场景+动作>

3. `parameters`: `mode=pro`（1080P）、`aspect_ratio=9:16`、`duration=5`；模型 `kling/kling-v3-omni-video-generation`（1.2 元/秒；每条 5s ≈ 6 元，出片后按需裁 2.2–2.9s）
4. 走官方真人素材做参考，可保留毛孔、发丝、胡渣细节（不像 AI 磨皮脸）；**不要拿 AI 磨皮图当人物参考**（必出 AI 脸）。实测面部轻微漂移（AI 会略"美颜"）但全片可认。
5. 场景 prompt 通用尾巴：`电影感布光，真实摄影质感，浅景深，竖屏。不要出现任何文字、水印、品牌标识。`

### 1.8 后期与交付（PIL 层 + 装配）

- **字幕**：底部居中 `y≈1560`，46px 白字 + 3px 黑描边（带 alpha 淡入）
- **贴片三件套**（对标样片）：`burst` 黄色爆炸星形多边形（24 角）+ 深色字（带弹出缓动）；`highlight` 白底 + 黄描边圆角胶囊 + 深色字；`price` 金色大字（`#FFD54A`）弹入 + 过冲缓动 + 旁边小字「到手价」（⚠️ 价格类已于 2026-09-17 作废，见 §五）
- **常驻角标**：右上「海尔 · 迷你便携剃须刀」（`enable` 区间避开片尾卡）
- **渐变压暗条（scrim）**：文字压在画面上时先铺 `y0→y1` 黑透明渐变，保证可读性
- 字体：`/System/Library/Fonts/PingFang.ttc`（`ImageFont.truetype(PING, size, index=1)` 取粗体）✓ 中文正常
- ¥169 大字写法：`scale = 0.6 + 0.45*ease_out(t)`，带过冲；参考实现 `scripts/overlay_anim.py`、`scripts/build_ad.py`
- 逐镜归一：`scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=25,setsar=1`
- **取镜偏移**：一条 5s 生成里前后段质量差别很大（实测"照镜自信"前段在东张西望、后段才是微笑）→ 逐镜加 `-ss <偏移>` 取最好的一段，别默认从头用
- 配音：edge-tts 分段（`--rate=+20%`）→ `ffprobe` 实测每段时长 → **据此定镜头时长**（实测 5 句 = 2.95/2.86/2.76/2.57/2.81 = 13.95s，正好压 15s）
- 排轴：`[0]adelay=150|150[x1];…;[x1][x2]…amix=inputs=N:normalize=0,afade=t=out:st=14.3:d=0.7,apad[a]`；**必须加 `apad`**（否则音轨短于视频时 `-shortest` 会把成片截短，实测 15s 被截成 13.1s）；`-t 15` 与 `-shortest` 同时用，输出才是完整 15s
- 一步出片（秒级）的配音混音配方：

```
ffmpeg -loglevel error -y -i 静音视频串.mp4 -i s1.mp3 -i s2.mp3 ... \
  -filter_complex "[1]adelay=150|150[a0];[2]adelay=2620|2620[a1];...;[a0][a1]...amix=inputs=N:normalize=0,afade=t=out:st=<总长-0.7>:d=0.7,apad=pad_dur=0.4[a]" \
  -map 0:v -map "[a]" -t <总长> -shortest -c:v copy -c:a aac -b:a 160k -movflags +faststart 输出.mp4
```

> 要点：① `apad=pad_dur=0.4`（有限；裸 `apad` 不带参数 = 无限静音流 → 编码器空转，实测挂死 6 分钟、写出 16MB 无 moov 音频）② 视频串作 `-map 0:v` 并 `-c:v copy`（不重编码）③ 音频序号从 `[1]` 起（0 是视频）④ **别先导 m4a 再 mux** —— 多一步就多一个挂死点。

### 1.10 踩坑清单

1. **不要把静图推近当镜头**（用户原话「把贴图运动起来」）→ 产品镜头也要 AI i2v 出真运动。
2. **官方宣传图上的文字会被 AI 一起"动"起来** → 裁剪时避开；用色块硬盖会产生横向涂抹条纹（更糟）。
3. **`-ss` 取偏移**：同一镜前后段质量不同（如"四处张望→微笑"），取表情更好的后段。
4. **任务跟踪文件要合并不要覆盖**：`json.dump({tag:tid})` 覆盖写会丢上一个任务的 id。
5. **合成音轨必须 `apad`**：否则配音短于画面时与 `-shortest` 一起把成片截短。
6. 贴回后的镜头才进成片；未贴回的镜头里产品形态会与前后的官方形态冲突（用户一眼看出）。
7. 长命令（尤其带 heredoc/awk 的巨型一行）会被 hardline 拦 → 落成 `.sh` 再 `bash` 跑。
8. 「看表 / 照镜 / 整理领带」这类动作 AI 容易演成"四处张望" → 用 `-ss` 偏移取后段或重生成。

### 1.11 发布前像素级自检清单（逐项必过）

1. **调 ffprobe**：duration / 1080×1920 / 25fps / h264+aac 齐全。
2. **freezedetect**：`-vf freezedetect=n=-60dB:d=0.8` 数 freeze_start，必须为 0。
3. **语音落点**：`silencedetect=n=-38dB:d=0.15` 读 silence_start/end 成对 → 每句台词的语音区间必须落在**对应镜头内**（⚠️ 别把"句中停顿"误读成"句首静音"，edge-tts 句首静音只有 ~0.18s，正常）。
4. **像素级放大**：把**交付文件**（不是中间素材）按镜头裁产品区放大 2 倍看图 → 金网有编织细节（不是色块/粗环）、Haier 字母无乱码。
5. **贴片遮挡**：highlight 胶囊 / 贴纸**不得盖住 Haier 或刀网**（合成卡里 Haier 在机身底部，胶囊放 y≈250 顶部区才安全）。
6. **文字不压产品**：¥169 与顶部角标至少留 70px，且不得压产品顶边。
7. **合成特效边界**：PIL 画的"水流/光扫"必须 `GaussianBlur(3~32)` 软化，否则出硬边白条，一眼假。
8. **音轨**：volumedetect mean ≈ -20~-26dB、max < -1dB（不削波）。
9. 交付前量化验收：`scripts/verify_motion.py`（冻结区间必须 0）+ 抽帧网格肉眼核字幕/尺寸/顺序。

## 二、真实感 / 抓拍拍法（旁白 VO ＋ 生活抓拍）

### 2.1 触发

用户说「**人物不真实。太假**」，或发一条**样片**说「看看样片的真实度 / 照这个标准」。
→ 这时**不要**去调分辨率、也不要去改台词；先按本文把"真实感"的四个来源逐条对齐。

### 2.2 第一步：先把样片拆开（用户发的样片就是验收标准）

用 `ffprobe` 拿元数据 → 按 5%~95% 抽 7 帧拼图 → 再对**产品特写**和**人脸**各做一次 2 倍放大细看 →
`voice_stt_local.py` 转写它的音频（这一步最容易被忽略，但常常直接给出答案）。

实测样例（用户发的吹风机 15s 片，544×960 / 24fps / 有音轨）：

| 维度 | 样片做法 | 我们 v11 的错法 |
|---|---|---|
| **拍法** | **画外旁白（VO）＋生活抓拍**，全片**没有人对着镜头念台词** —— 音频转写是"每天最治愈的十分钟是给女儿吹头发…" | 全程对着镜头说话＋对口型 ✗ |
| **光** | **暖色实用光**（地板灯/窗光）作主光，有方向、有衰减、有真实阴影 | 影棚平光、无方向 ✗ |
| **皮肤** | 法令纹、眼袋、肤色不均、真实牙齿（笑到眯眼、嘴角不对称） | 磨皮、完美对称、网红脸 ✗ |
| **空间** | 生活道具（台灯/相框/花/抱枕）＋**浅景深** | 空背景或糊背景 ✗ |

**结论（关键洞察）：「对口型」本身就是最大的"假感"来源。** 用户自己的标杆片选择"旁白＋抓拍"绕开了它。
我们之前的路线是 R2V 自带人声 + videoretalk 重对口型 —— 当用户开始拿"真实度"说话时，优先改成旁白版。

### 2.3 杠杆 1：参考人像必须是"写实抓拍风"，不是影棚模特照

**影棚灰底＋磨皮的参考图 → 生成出来必然是假脸**（v11 就是这么来的）。
生成参考人像时把下面这段写进 prompt（实测有效：4 张候选真实感 9~9.5/10）：

```
真实摄影照片，不是影棚商业模特照。光线是室内自然光或真实实用灯（窗光/台灯/吊灯），
有明确方向、有明暗过渡与真实阴影，不要平光、不要打光板感。
皮肤是真实皮肤：可见毛孔、细纹、鼻唇沟阴影、淡淡胡渣、肤色不完全均匀；
不要磨皮、不要塑料感、不要网红脸、不要过度对称的脸。
头发自然（有少量碎发、不油亮）。背景是真实生活/办公空间（有生活道具与轻微杂乱），有景深虚化。
表情自然放松、抓拍感，不是看镜头的商业摆拍。画面中不要出现任何文字、水印、logo。
```

再各加一句人物设定（年龄/衣着/在哪/在干什么），例如"31岁中国男性，黑色方框眼镜，深藏青西装外套＋白衬衫、领带松开，在办公室窗边工位，午后窗光从侧后方照进来，像加班间隙被随手拍到"。
→ 出 4 个候选拼图发飞书让用户挑（他挑得很快，比我们自己拍板稳）。

⚠️ 参考人像会原样决定视频人物的胡子与表情（候选图带小胡子/皱眉，视频里就是小胡子/皱眉，视频 prompt 写「上唇绝对没有胡须」「不要皱眉」**完全无效**）→ 人像候选必须写死：上唇完全光洁 + 下巴只有极淡青灰胡渣 + 眉毛放松不皱 + 看着镜头自然微笑 + 看起来年轻。

### 2.4 杠杆 2：视频 prompt 里加"写实四件套"（放在 HEAD 段，每段都带）

```
【光线】室内真实光源：车里=白天自然窗光侧照，洗手间=镜前暖白灯，卧室=床头暖光；
侧光/侧逆光为主，有明确明暗过渡和真实阴影；不要平光、不要打光板、不要影棚感。
【皮肤】真实皮肤质感：可见毛孔、细纹、鼻唇沟阴影、淡淡胡渣、肤色不完全均匀；不要磨皮、不要塑料感、不要网红脸。
【头发】自然蓬松、有碎发，不油亮。
【画面】浅景深；背景有真实生活道具（车里=中控水杯纸巾，洗手台=牙杯毛巾，床头=台灯充电线）；轻微手持晃动感。
【人物】全程不说话、不做口型、不面对镜头念台词；神情自然放松（低头微笑或专注手上动作），像被抓拍到的生活瞬间。
```

**同时把台词从 prompt 里拿掉**：R2V 只要看到引号里的台词就会开口型。旁白版做法是 prompt 只写动作、不写台词。

> 现行产品锁模板里的同一铁律（一刀不改）：**「全程没有人直视镜头（生活抓拍感）：眼睛看向手里的产品、斜下方或环境，绝不看向镜头方向；在镜子前的镜头里要侧一点脸、看镜中的自己（不要正脸朝着镜头方向）；全程不说话、不做口型、不面对镜头念台词；做具体的事情、有生活化的反应与表情变化。」**

### 2.5 杠杆 3：旁白版装配 —— 一条整 30s 音轨，不要段内音频

不要跑 videoretalk，也不要逐段换音轨 —— 直接生成一条**贯穿全片的旁白轨**，装配时只叠它。
用 `scripts/build_vo30.py`：

```bash
python3 scripts/build_vo30.py zh-CN-YunxiNeural "+5%" vo30.mp3   # 逐句 TTS 按字幕落点拼成 30s 音轨
```

它的做法：按 `overlay_cfg.json` 里每条字幕的 `start` 逐句 edge-tts → 用 `adelay=<ms>|<ms>` + `amix=inputs=N:normalize=0:duration=first` 叠到 30s 静音底上（`normalize=0` 必须写，否则 amix 会把电平压小）。

装配时把三段视频 concat（**不要** concat 它们的音频），音频单独 map 这条 VO：
`[vo:a]aresample=44100,apad=whole_dur=30.5[aout]`，最后 `-shortest`。
→ 好处：旁白天然连贯（不会像逐段配音那样"换人"），也彻底省掉对口型环节。

### 2.6 杠杆 4：音色 —— 生活化旁白用年轻声线

同一条配音轨**一定要自己听/量过再交付**：edge-tts 各音色的基频中位数可用于判断
（实测 云希 `zh-CN-YunxiNeural` ≈168Hz 年轻自然 / 云扬 `zh-CN-YunyangNeural` ≈129Hz 成熟播报）。
样片那种"第一人称生活化旁白"用年轻声线更贴，但要**把两条都发用户听**再定，别自己拍板。

### 2.7 坑

- **edge-tts 会间歇性 `NoAudioReceived`**（连续快速请求被限流）。必须**重试**：单句最多 6 次、退避 4~7s；用 `capture_output=True` 把 stderr 收下来打日志，否则只看到 exit 1 不知道原因。实测 6 句里会有 1~2 句首次失败，重试后全部成功。
- 有声文件对比别只看文件大小（两条不同音色的 mp3 可能字节数相同）→ 用 `md5` + 基频确认。
- **不要把它当"已验证成片"**：本拍法在 2026-09-17 完成到"候选已出、管线已备、等用户选角"的阶段，用户的最终验收还没给。先按用户反馈走。

## 三、全运动镜头铁律

> 2026-09-16 用户纠偏：「**最新的又成贴图了**」（此前 09-15：「像PPT / 图片拼接 / 露灰框」）。本节是权威口径。

### 3.1 规则

1. **每一个镜头都必须是 AI 生成的真运动视频。**
   静图 + `zoompan`/Ken Burns/位移 充镜头 = 用户判「贴图」。静图版虽然 0 元，但会被整片判废 —— **省钱不能省在"画面是不是真动"上**。
2. **花字动画不算镜头运动。** PIL 逐帧叠字（`scripts/overlay_anim.py`：弹入、错峰淡入、渐变遮罩条、尺寸徽标）只是信息层；主体不动，用户照样判贴图。
3. **产品保真与"真运动"的当前关系**：把官方实拍照片当 `first_frame` → AI 产出真运动（首帧法）。🟡 首帧法已降为**备选**（锁尺寸、锁不住细节：5s 内金网退化）；产品必须被认出的镜头改走**官方真像素插入镜**（§1.5）。
4. **交付前必须量化验运动**，肉眼"看着还行"不算验过：

```bash
python3 scripts/verify_motion.py 成片.mp4
```

- 冻结区间（freezedetect）**必须为 0**（硬指标）
- 帧间差均值（`tblend=difference` + signalstats YAVG）作辅证，越小越"糊"
- 15s v2 通过验收的实测值：冻结 0；帧间差 A 3.45 / B 2.59 / C 4.37 / D 1.57

### 3.2 15s 全运动版结构（v2 验收通过，可复用；口型环节已作废，见 §五）

| 镜头 | 内容 | 时长 | 做法 |
|---|---|---|---|
| A | 官方真人实拍·剃须 | 2.7s | 首帧法（旧：`videoretalk` 口型对齐配音 0.08 元/秒 → 现改旁白版） |
| B | 产品特写 | 4.9s | 首帧法（官方拉页图裁 9:16）→ 现：官方真像素插入镜 |
| C | 真人手从内袋取产品 | 4.6s | 首帧法（拉页图-3）+ 尺寸徽标花字层 |
| D | 产品英雄（缓慢推进） | 2.8s | 首帧法（拉页图-12，自带 74mm/39mm 标注）+ ¥169 花字层（价格已作废） |

- 首帧字段：`media:[{"type":"first_frame","url":...}]`（可灵 `kling-v3-omni-video-generation` mode=pro = 1080P；万相3.0 `wan3.0-video`；均 1.2 元/秒）
- 镜头D 实测：**AI 缓慢推进时官方 74mm/39mm 标注线不变形** ✓ → prompt 必须写「不要改变画面中已有的标注线与文字，只让背景光影轻微变化」。
- 配音：edge-tts 分段，每段 ≤5s（`--rate=+20%`），逐段实测时长再定镜头时长（实测 s1/s2/s3 = 2.64 / 4.78 / 4.58s）。
- `drawtext` 字幕：`enable='between(t\,0.3\,2.6)'` 逗号要转义。

### 3.3 素材纪律（顺手把尺寸问题一起解决）

- 客户官方拉页（`拉页图-*.jpg`）通常自带**真人 + 使用场景 + 尺寸标注**三件套，先翻官方物料再自己造图：
  - `拉页图-2` 商务男士侧脸剃须（真人肤质）→ 镜头A
  - `拉页图-3` 真人手从大衣内袋取产品（官方标注「鸡蛋大小 / 7cm / 70g」）→ 镜头C
  - `拉页图-12` 产品英雄图（自带 74mm×39mm 尺寸标注）→ 镜头D
- **避开官方文案**：只裁"人物+产品"完全无字的窗口。❌ 不要用色块硬盖，也不要用"逐行取背景色向左延展"（实测产生横向涂抹条纹，比文字更糟）。
- 官方自带的尺寸标注**保留** —— 它正好是"尺寸真实"的视觉证据（用户在意尺寸）。
- 用户对失真的量化判据：真机 74×39mm（鸡蛋大小、握在手心约占手掌 2/3 宽）；成片里产品 ≈1.5~2 倍手掌宽 = **严重失真**必须回炉。让模型"画"产品它必然把主角放大 —— 这是**流程问题，不是提示词问题**。

## 四、分镜正文措辞规则（`project.json → segments`）

产品锁头 `templates/product_lock_head.txt` 管**全局**，分镜正文管**这一镜拍什么**。
下面 6 条是 2026-09-18 一轮 5 段 wan3.0-video 成片逐帧核验抓出来的**正文级坑 + 修法** ——
锁头里已经写死的东西，正文里仍要再写一遍才压得住（模型对锁头的执行是"倾向"不是"硬约束"）。

### 0. 尺寸与刀网：现行锁口径（2026-09-19 定，优先于旧文）

① **手持比例：0.7~0.8 倍手掌长（不是 1.1~1.3 倍）**

- 真机 HSQ1 = **74mm 长**，成人掌长约 100mm → **机身总长 ≈ 手掌长的 0.7~0.8 倍**（比手掌略短，约一根食指长）。
- 早期为治"产品太小"，把下限写成"**≈ 手掌长 1.1~1.3 倍**" → AI 把机器画得**比手掌还长** → 侧视就是个**保温杯/水杯**，用户直接说"认不出是什么东西"。
- 现行锁措辞（已在 `templates/product_lock_head.txt` 的【尺寸下限】与 `product_profiles.json` 的 `video_lock.size`）：
  「不少于画面高度的八分之一」+「手持时机身总长 ≈ 手掌长 **0.7~0.8 倍**」+「**绝不许比他的手掌还长**（画长了就变成保温杯／水杯）」。
- **通用教训**：写任何"比例下限"前，先拿真机尺寸除以参照物尺寸算一遍，别凭感觉拍倍数。

② **真机机头 = 向上拱起的金色球面网罩（穹顶状）**

- 锁里只写"黑环＋金色网面" → AI 一律画成**平的黑色盖子**（侧视 = 杯盖）→ 产品识别失败。
- 官方 `拉页图-7.jpg` 与 `产品图/正面图_cropped.png` 对照确认：机头是**明显拱起的金色球面网罩** + 宽黑环，机身是枪灰金属直筒 + 一次白色 Haier。
- 现行措辞：「机头（黑色环带＋**向上拱起的金色球面网罩**）直径与机身相同；机头顶上必须是拱起的金色球面网罩，**不是平的黑色盖子、不是银白盘**」。
- 另两条硬事实（写 prompt 压不住，要靠素材/构图解决）：**机身会被拉长** —— prompt 写"总长≈直径1.9倍"，模型仍按"电剃须刀=细长罐"画成 **2.56**（+35%）→ 三条同时上：写 **1.8** ＋说**短圆柱**＋**换机位**（别竖举到脸前，改斜握胸前、机头朝斜上方）；**产品小到画面高 1/10 以下时机头糊成深色块** → 给足尺寸（≥1/6 画面高）＋写「机头朝上、黑环＋金网清晰可辨、机身完整不糊」。

### 1. 尺寸：写正向下限，禁写"很小 / 一小截"

- ✗ 血泪原文：`这台机器很小——长度不超过画面高度的六分之一`、`拿在手里就是一小截（比他的手学还短）` → 生成结果被用户判"**产品太小**"（同一问题他第二轮投诉）
- ✓ 改成：`机身总长大约等于他手掌长度的 1.1~1.3 倍、在画面里约占高度的六分之一、黑环与金色网面清晰可辨`
  → ⚠️ 数值部分已被 §4.0 覆盖：**1.1~1.3 倍 → 0.7~0.8 倍**（"写正向下限、禁写很小/一小截"的原理不变）
- 原理：模型对程度词/否定词几乎照单全收（"很小"→ 真的画得很小）；下限要写成**可比的物理量**（手掌长倍数 + "清晰可辨"）才压得住。

### 2. 开场第 1 秒（多钩子 A/B 必看）

- 症状：3 个钩子分别要求"镜前摸下巴 / 玄关行李 / 镜前看下颌"，实测**三条第 1 秒都是同一张刀网微距** → 前 3 秒全一样，钩子 A/B 对照失效。
- 根因补充：`wan3.0-video` 用 `input.images`（多参考图）时**把参考图1 当作画面首帧**；要"开场就是他本人"→ **把图1 换成男主图**（代价：少一个金色校准锚点，刀网金色有变浅风险，换完必须重核刀网）。核验抽帧**必须含首帧（0.2~0.5s）**。
- 修法：正文开头写 `开场第 1 秒就是他本人（上半身/侧脸）在×××，绝不要用刀网微距或产品特写开场`；微距开场只留给**一个**变体当招牌（悬念型）。

### 3. 场景锁死（防场景漂移）

- 症状：正文写 `仍在车内驾驶座…对着后视镜`，实测尾部约 9s **漂到洗手间**（瓷砖墙 + 洗手池）。
- 修法：段末补一句 `场景锁死：全片都在车内——绝不出现洗手间、瓷砖墙、水龙头、洗手池或镜面（车内后视镜除外）`。

### 4. logo 不外溢

- 症状：镜前镜头里 `Haier` 被画到**他的裤子上**（也出现过画到镜面/墙面）。
- 修法：`只有机身上有一处白色 Haier，衣服、裤子、墙面、镜面上都不得出现任何文字或 logo`。

### 5. 产品必须完整（防"保温杯"）

- 症状：要求"把机器举到眼前端详"的镜头，生成了**一根没有刀头的光筒**（像保温杯）—— 因为该镜没写"刀头同时可见"。
- 修法：`机器是完整的一台：机身与机头（宽黑环＋环内饱和香槟金网格）同时可见，机身与机头连成一根等粗的直筒`，并加一句 `绝不能变成一根没有刀头的光筒`。

### 6. 机头视角

- 锁头已禁"机头正对镜头"，但模型仍会**用它当开场**（三个钩子同时中招）；正文里再写 `从侧前方 3/4 视角、画面里同时看得到机身侧面与刀网边缘` 才稳。
- 例外：**"刀网微距"作为单个钩子的招牌开场是有效的**（质感被用户认可），但**只能给一个变体用**。

### 7. 分镜不能只罗列场景（2026-09-17 用户反馈）

原话「人物太呆滞，而且没有情景，单纯的罗列场景，能不能丰富一下」。
反例：电梯镜只有「他走进电梯间，步伐自信，镜头跟随」。
正解：每个镜头给**动作链＋动机＋表情变化** —— 「低头看手表 → 对着不锈钢门板上的倒影理衬衫领口 → 抬头，眼神从疲惫转为自信」。
自检：这个镜头主角**为什么**做这个动作？有没有前后两拍的变化？

### 8. 每轮生成后的核验顺序（不许跳）

1. **产品区放大拼图**（`scripts/product_fidelity_zoom.py` 或自建 PIL：固定相对裁框 + LANCZOS 放大）→ 看 形态（长径比/是否大圆盘）/ 刀网是否饱和香槟金 / logo 是否乱码
2. **全帧总览拼图**（每段 4 帧）→ 看 ①人物是否直视镜头 ②镜中倒影是否同一人、有无第二张脸/重影 ③产品尺寸是否过小 ④文字/logo 是否外溢 ⑤场景是否漂移
3. 逐段给 **放行 / 重做** 结论，**只重跑有问题的段**（本轮：h1 h2 m1f c1 重做 = 18 元，h3 放行）
4. **未通过前不装配交付**（装配 0 元，但返工花的是生成费）

### 9. 复核命令（r2v 版，抽帧别用抽样判时间轴）

```bash
FF=~/video-tools/bin/ffmpeg
# ① 全片网格（每 2.5s 一帧，三段各 4 帧）
$FF -y -i segN.mp4 -vf "fps=1/2.5,scale=392:-1,tile=4x1" -frames:v 1 rowN.jpg
# ② 关键细节放大（充电口/logo/网面）——用精确 -ss，不要靠抽样
$FF -y -ss 5.2 -i seg3.mp4 -frames:v 1 -vf "scale=520:-1" port.jpg
```

逐项核对：产品是否自然在场景里（手部接触/光影）· 网面是否香槟金菱形网格 · Haier 是否完整正确 · **接口位置是否与官方图一致** · 有无 AI 乱码文字。
⚠️ **抽帧时间轴别用 `fps=1/N` 抽样去判断**：抽样出来的帧时间戳不可靠（实测按抽样误判"字幕错位"，用 `-ss` 精确抽帧复核后 6/6 全部对齐）。判断时间轴一律 `-ss <t>`。


- 参考图准备：官方 2000×2000 PNG → `convert("RGB")` → `thumbnail((1100,1100))` → jpg → scp 上 `yunvela.com/dh/`

**（b）像素纪律五步（"产品像素永不经过 AI"的合成卡路线，已被否决）**

1. 官方图抠透明 PNG（`cutout_product.py`：白底亮度阈值转 alpha，2000px 原图 → 保留网孔/logo 原像素）
2. 产品卡 = 官方 PNG 用 PIL/ffmpeg **只做几何变换**（缩放/位移/轻微浮动）+ 光影扫过 + 接触阴影，叠在**真运动的场景视频**上（场景取 AI 生成镜头的重虚化版，虚化同时把 AI 画错的产品抹掉 ✓）
3. 剧情镜头里**产品不出现**（手部只做"摸下巴/整理领口/收拾行李"，避免 AI 画产品）
4. 参数/价格/尺寸标注用 **PIL 直接画**（矢量清晰，不是 AI 生成的字）
5. 产品卡的动效足以满足"有真运动"：背景场景在动 + 产品缩放/浮动 + 高光扫过 + 水流/呼吸灯
