# 场景化剧情广告（类别级做法 · 2026-09-16 定型）

## 0. 权威口径（最高优先级）

用户 09-16 纠偏原话：**「我需要的是场景化的，不是这种把贴图运动起来的，样片不是给你看过」**

- ✅ 交付形态 = **AI 生成的「真人 + 真实环境 + 剧情动作 + 运镜」多镜头片**
- ❌ 「官方静图 + 运镜 / 整片用官方图当首帧」= 用户判定**「把贴图运动起来」**（本项目 v1、v2 连续两次被判废）
- 官方真图只承担：**产品特写插镜**、**片尾价格卡**
- 产品识别一律靠**贴回后的真品镜头**（见 §4），不靠 AI 画

## 1. 开工第一步：把用户的"样片"挖成规格表（禁凭记忆）

样片（微信/飞书传来的视频）落盘后目录形如 `/tmp/newsample/doc_*_video/`，内含：

| 文件 | 用途 |
|---|---|
| `a.wav` | `ffprobe` 量时长 = **交付规格**（实测两条样片 = 15.07s / 30.07s → 正好对应"15s / 30s 两种规格"） |
| `a.txt` | 样片台词 STT 全文 → 反推**叙事结构**（痛点 → 场景 → 产品 → 使用 → 结果 → 价格/CTA） |
| `grid.jpg` | 抽帧网格 → 反推**镜头数、场景、字幕位置与句式、贴片动效样式、运镜** |

> ⚠️ 样片里听来的说法**不得当话术**：官方物料没有的词一律不用
> （HSQ1 实测：样片说"鸡蛋大小"，官方无此卖点 → 禁用）。

## 2. 剧本结构（15s 通勤剧情版 = 6 镜 × 2.2–2.9s）

| # | 时长 | 画面（人+环境+动作） | 字幕（跟配音） | 贴片 |
|---|---|---|---|---|
| 1 | 2.9s | 车内驾驶座，早高峰，抬腕看表、神情焦急 | 早上起晚了，胡子都没来得及刮 | 黄爆炸贴纸「差点忘了刮」 |
| 2 | 2.8s | 侧身拉开手套箱，取出一个小圆柱握在手心 | 车里常备一个，随手就能补 | 高亮胶囊「迷你机身 · 随手一塞」 |
| 3 | 2.9s | 仰头把产品贴在下颌快速补剃（此镜走贴回） | 八千五百转，几下就干净 | 高亮胶囊「8500转高速马达」 |
| 4 | 2.6s | 抹下巴、照镜，表情由焦急转轻松自信 | 见客户前，清爽上线 | — |
| 5 | 2.2s | 产品英雄（官方真图，含尺寸标注） | 镀钛刀网 · 充电1小时 · 续航90天 | 金色大字「¥169」弹入 |
| 6 | 1.6s | 写字楼电梯间，握着产品整理袖口 | — | 黄爆炸贴纸「出门带它一个就够」 |

规律：**每镜都必须有"人 + 环境 + 动作 + 运镜"**；字幕=口语短句且与配音逐句对应；贴片每镜最多一条。

## 3. 人物一致性（同一男主贯穿全片）

- 用官方真人素材裁一张**纯人物参考图**：头肩+衣服，**不能含产品、不能含文字**
  （例：`拉页图-2.jpg` 裁 `(120,300,750,940)`；裁完 scp 到 `yunvela.com/dh/`）
- 每次生成都带 `media:[{"type":"refer","url":"<人物参考图>"}]`，prompt 开头固定写：
  「画面中的人物是图1中的亚洲商务男士，严格保持他的相貌、发型与深色西装造型一致：」
- 实测：面部轻微漂移（AI 会略"美颜"）但全片可认；**不要拿 AI 磨皮图当人物参考**（必出 AI 脸）
- 场景 prompt 通用尾巴：`电影感布光，真实摄影质感，浅景深，竖屏。不要出现任何文字、水印、品牌标识。`
- 模型/参数：可灵 `kling/kling-v3-omni-video-generation`，`mode:pro`、`duration:5`、`aspect_ratio:"9:16"`
  （1.2 元/秒；每条 5s ≈ 6 元，出片后按需裁 2.2–2.9s）

## 4. 产品保真：贴回（唯一可靠路径）

AI 自由生成的产品**必错**（实测被画成扁平剃须刀 / 变形 / 尺寸夸张）→ 场景生成完再跑一次**贴回**：

- 模型 `wan2.7-videoedit`，`input.media = [{"type":"video","url":<场景视频>},{"type":"reference_image","url":<官方干净产品图>}]`
- 官方文档示例本身就是"指令 + 参考图 = 局部替换"，prompt 模板：

  > 把视频里男士手中和下颌处的剃须刀，替换成参考图1 中的剃须刀：严格保持参考图1 的形状、比例、颜色、材质与 logo 一致；
  > 产品的位置、大小、朝向、运动跟随原视频，不要改变产品的尺寸，不要放大产品。
  > 画面其余内容（人物、动作、镜头运动、光线、背景）保持不变，不要添加任何文字。

- 实测：`resolution:"1080P"` 入 1080×1920 → 出 1080×1920 ✓，产品变为官方形态（黑圆柱 + 金顶带 + Haier 在机身下侧）、
  握在手心尺寸自然、跨帧稳定 ✓ 融合无痕迹 ✓
- 参考图准备：官方 2000×2000 PNG → `convert("RGB")` → `thumbnail((1100,1100))` → jpg → scp 上 `yunvela.com/dh/`
- 可复用脚本：`/tmp/cmp/submit_pastereturn.py <本地视频> <标签>`（上传 → 提交 → 落 `tasks_pr2.json`）

## 5. 字幕 + 贴片动效（PIL 逐帧，比 ffmpeg drawtext 更可控）

- **字幕**：底部居中 `y≈1560`，46px 白字 + 3px 黑描边（带 alpha 淡入）
- **贴片三件套**（对标样片）：
  - `burst` 黄色爆炸星形多边形 + 深色字（带弹出缓动）
  - `highlight` 白底 + 黄描边圆角胶囊 + 深色字
  - `price` 金色大字（`#FFD54A`）弹入 + 过冲缓动 + 旁边小字「到手价」
- **常驻角标**：右上「海尔 · 迷你便携剃须刀」（`enable` 区间避开片尾卡）
- **渐变压暗条**（scrim）：文字压在画面上时先铺 `y0→y1` 的黑透明渐变，保证可读性
- 参考实现：`scripts/overlay_anim.py`（本项目 `/tmp/cmp/build_ad.py` 为完整总装版）

## 6. 时间轴与合成（音频是最大坑）

1. 逐镜归一：`scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=25,setsar=1`
2. **取镜偏移**：一条 5s 生成里前后段质量差别很大（实测"照镜自信"前段在东张西望、后段才是微笑）
   → 逐镜加 `-ss <偏移>` 取最好的一段，别默认从头用
3. 配音：edge-tts 分段（`--rate=+20%`）→ `ffprobe` 实测每段时长 → **据此定镜头时长**
   （实测 5 句 = 2.95/2.86/2.76/2.57/2.81 = 13.95s，正好压 15s）
4. 排轴：`[0]adelay=150|150[x1];…;[x1][x2]…amix=inputs=N:normalize=0,afade=t=out:st=14.3:d=0.7,apad[a]`
   - **必须加 `apad`**：否则音轨短于视频时，`-shortest` 会把成片截短（实测 15s 被截成 13.1s）
   - `-t 15` 与 `-shortest` 同时用，输出才是完整 15s
5. 交付前量化验收：`scripts/verify_motion.py`（冻结区间必须 0）+ 抽帧网格肉眼核字幕/尺寸/顺序

| **合计** | | | **≈39 元 / 条 15s** |

30s 版：在 15s 基础上再补 3 个场景（电梯间/洗手间/酒店房间）≈ +18 元。**开工前先算账、先确认余额**（欠费报 `Arrearage`）。

## 8. 坑（都踩过）

- 长命令（尤其带 heredoc/awk 的巨型一行）会被 hardline 拦 → 落成 `.sh` 再 `bash` 跑
- 首帧/参考图里**绝不能留官方文案**：❌ 色块硬盖、❌ 逐行取背景色向左延展（产生横向涂抹条纹，比文字更糟）
- 场景里 AI 画的产品只算"通用造型"，**不做产品识别**；识别一律用贴回后的真品镜头
- 「看表 / 照镜 / 整理领带」这类动作 AI 容易演成"四处张望" → 用 `-ss` 偏移取后段或重生成
- 别把"官方图 + 运动/首帧法"堆满全片充交付 —— 用户会直接判"贴图运动起来"
