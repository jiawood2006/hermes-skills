## 1. 路线铁律：只要"贴上去"，用户就判贴图

用户 2026-09-16 原话：**「这种又成贴图了」**。被判贴图的两种做法：

| 做法 | 结果 |
|---|---|
| 官方图抠图 → 叠到 AI 背景上（合成卡） | ❌ 用户一眼识破。查过 alpha：残留半透明像素铺满整幅矩形，但**修干净也没用** |
| AI 出人/场景 + 产品卡贴片按时间轴拼 | ❌ 同上 |
| 官方产品图 Ken Burns 缓慢推近当产品镜头 | ❌ 同上（旧方案，已在 SKILL.md 标注废弃） |

**根因**：产品像素不是**该场景渲染出来的** —— 光影方向、透视、手部接触关系必然不自洽。
修 alpha / 加阴影颗粒只是"更不容易被发现"，不是解决。

**正解 = r2v 多参考图**：`wan2.7-r2v`，`media` 里同时给
`{type: reference_image, url: 官方产品图}` + `{type: reference_image, url: 人物图}`，
prompt 用「图1 / 图2」指代。产品身份由参考图锁定，模型**在场景里把它画出来**：
手持、贴脸补剃、水龙头下冲洗、插线充电、塞进旅行包 —— 全部光影自洽。

用户验收口径：**「产品细节基本满足了」**（即：接受 AI 固有轻微漂移，换取"无贴图感"）。
用户原话确认过代价：「代价：产品细节是AI画的，会轻微漂移」。

r2v prompt 里必须写死的两条（不写就漂）：
- 「顶部黑色环带内嵌**浅金色蜂窝编织网状**刀网（金色细密编织网孔，**绝对不是光滑实心金色圆盘、不是放射状图案**）」
- 「机身下部印有**完整清晰的 Haier 英文字母**（五个字母拼写正确、清晰可读，不能变形乱码）」

## 2. 产品结构事实：先从官方图查证，再写 prompt（血泪）

2026-09-16 用户纠正：**「真机是底部有 Type-C 充电口，不是侧面，你设计的不是」**。

- HSQ1 实际结构：**Type-C 充电口在【机身底部端面】**，与**电源键同一面**，旁边有小指示灯；
  **左右侧面是光滑的、没有任何接口或开孔**。
- 这条信息**本来就在** `references/product-fidelity-decision-tree.md` 的形制表里（"另一断面：圆形电源键 + Type-C 充电口"）
  —— 我没读表就写 prompt，把线画到了侧面。
- 官方图指认：`~/Desktop/电商素材/剃须刀/产品图/3.png` = 底部端面特写，一眼可见电源键 + Type-C 槽 + 指示灯。

**做法（写进每一条涉及产品的 prompt）**：
1. 打开官方图，把这几个问题逐条答完：接口在哪一面？按键在哪一面？哪一面是刀头？哪一面有 logo？侧面/背面有没有开孔？
2. prompt 正反两面都写死：`Type-C 充电口在【机身底部端面】（与电源键同一面），机身左右两侧光滑、绝对没有充电口或任何开孔。`
3. 涉及充电镜头，给镜头写法：`剃须刀【侧躺在柜面上、底部端面朝向镜头】，线从【底部充电口】接入，底部指示灯亮起蓝光`。
4. 生成后**放大抽帧复核该细节**（见第 3 节）——这次靠复核抓到并修对了。

## 3. 交付前复核（r2v 版）

```bash
FF=~/video-tools/bin/ffmpeg
# ① 全片网格（每 2.5s 一帧，三段各 4 帧）
$FF -y -i segN.mp4 -vf "fps=1/2.5,scale=392:-1,tile=4x1" -frames:v 1 rowN.jpg
# ② 关键细节放大（充电口/logo/网面）——用精确 -ss，不要靠抽样
$FF -y -ss 5.2 -i seg3.mp4 -frames:v 1 -vf "scale=520:-1" port.jpg
```

逐项核对：产品是否自然在场景里（手部接触/光影）· 网面是否浅金色蜂窝编织 · Haier 是否完整正确 ·
**接口位置是否与官方图一致** · 有无 AI 乱码文字。

⚠️ **抽帧时间轴别用 `fps=1/N` 抽样去判断**：抽样出来的帧时间戳不可靠（实测按抽样误判"字幕错位"，
用 `-ss` 精确抽帧复核后 6/6 全部对齐）。判断时间轴一律 `-ss <t>`。
