# 分镜正文措辞规则（segment prompt wording）

产品锁头 `templates/product_lock_head.txt` 管**全局**，分镜正文（`project.json → segments`）管**这一镜拍什么**。
下面 6 条是 2026-09-18 一轮 5 段 wan3.0-video 成片逐帧核验抓出来的**正文级坑 + 修法** ——
锁头里已经写死的东西，正文里仍要再写一遍才压得住（模型对锁头的执行是"倾向"不是"硬约束"）。

## 1. 尺寸：写正向下限，禁写"很小 / 一小截"
- ✗ 血泪原文：`这台机器很小——长度不超过画面高度的六分之一`、`拿在手里就是一小截（比他的手学还短）`
  → 生成结果被用户判"**产品太小**"（同一问题他第二轮投诉）
- ✓ 改成：`机身总长大约等于他手掌长度的 1.1~1.3 倍、在画面里约占高度的六分之一、黑环与金色网面清晰可辨`
- 原理：模型对程度词/否定词几乎照单全收（"很小"→ 真的画得很小）；下限要写成**可比的物理量**（手掌长倍数 + "清晰可辨"）才压得住。

## 2. 开场第 1 秒（多钩子 A/B 必看）
- 症状：3 个钩子分别要求"镜前摸下巴 / 玄关行李 / 镜前看下颌"，实测**三条第 1 秒都是同一张刀网微距**
  → 前 3 秒全一样，钩子 A/B 对照失效。
- 修法：正文开头写 `开场第 1 秒就是他本人（上半身/侧脸）在×××，绝不要用刀网微距或产品特写开场`；
  微距开场只留给**一个**变体当招牌（悬念型）。

## 3. 场景锁死（防场景漂移）
- 症状：正文写 `仍在车内驾驶座…对着后视镜`，实测尾部约 9s **漂到洗手间**（瓷砖墙 + 洗手池）。
- 修法：段末补一句 `场景锁死：全片都在车内——绝不出现洗手间、瓷砖墙、水龙头、洗手池或镜面（车内后视镜除外）`。

## 4. logo 不外溢
- 症状：镜前镜头里 `Haier` 被画到**他的裤子上**（也出现过画到镜面/墙面）。
- 修法：`只有机身上有一处白色 Haier，衣服、裤子、墙面、镜面上都不得出现任何文字或 logo`。

## 5. 产品必须完整（防"保温杯"）
- 症状：要求"把机器举到眼前端详"的镜头，生成了**一根没有刀头的光筒**（像保温杯）—— 因为该镜没写"刀头同时可见"。
- 修法：`机器是完整的一台：机身与机头（宽黑环＋环内饱和香槟金网格）同时可见，机身与机头连成一根等粗的直筒`，
  并加一句 `绝不能变成一根没有刀头的光筒`。

## 6. 机头视角
- 锁头已禁"机头正对镜头"，但模型仍会**用它当开场**（三个钩子同时中招）；
  正文里再写 `从侧前方 3/4 视角、画面里同时看得到机身侧面与刀网边缘` 才稳。
- 例外：**"刀网微距"作为单个钩子的招牌开场是有效的**（质感被用户认可），但**只能给一个变体用**。

## 每轮生成后的核验顺序（不许跳）
1. **产品区放大拼图**（`scripts/product_fidelity_zoom.py` 或自建 PIL：固定相对裁框 + LANCZOS 放大）
   → 看 形态（长径比/是否大圆盘）/ 刀网是否饱和香槟金 / logo 是否乱码
2. **全帧总览拼图**（每段 4 帧）→ 看 ①人物是否直视镜头 ②镜中倒影是否同一人、有无第二张脸/重影
   ③产品尺寸是否过小 ④文字/logo 是否外溢 ⑤场景是否漂移
3. 逐段给 **放行 / 重做** 结论，**只重跑有问题的段**（本轮：h1 h2 m1f c1 重做 = 18 元，h3 放行）
4. **未通过前不装配交付**（装配 0 元，但返工花的是生成费）
