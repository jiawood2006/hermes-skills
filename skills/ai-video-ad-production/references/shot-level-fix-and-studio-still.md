# 逐镜头修复 + 官方真机影棚特写（2026-09-15 实测）

## 一、用户反馈的正确解法：「不是全片重做，是修失真的那几个镜头」
用户原话：**「你的失真也不是全部失真，部分镜头的部分产品细节失真太明显」**

**做法（必走）**：✗ 不要一被说失真就整片重来 → ✅ 逐镜头审计，只换坏的。

### 逐镜头审计脚本（可复用）
1. `ffmpeg -i v.mp4 -filter:v "select='gt(scene,0.25)',showinfo" -f null -` 正则抓 `pts_time` → 镜头边界
2. 取每个镜头**中段帧**，PIL 拼 4 列网格并在每格左上角烧「#序号 起-止 s」
3. 网格图交给视觉模型：逐格问「产品可见吗/失真吗/失真具体是什么」
4. 输出表：✅可留 / ⚠️一般 / ❌必须换 → 只重做 ❌ 与 ⚠️

本轮定位结果（供参考）：万相 r2v 生成的 10s 段里，**产品特写镜头最容易崩**（金网鼓成"盖子"、锥形身像电子烟、纯黑细棒无金网），而"人物手持远景""产品不在画面"的镜头基本安全。

## 二、官方真机影棚特写（**产品零失真的唯一可靠做法**）
原理：产品像素**全部来自官方图**，不做任何生成 → 永远不可能失真；只做"包装"（底、光、动效）。

### 生成脚本骨架（PIL + ffmpeg zoompan）
```
1. 找产品实体：solid = np.asarray(im).min(axis=2) < 200   # 深色/银色实体
2. 以实体 bbox 外扩 margin=0.30 裁切   ← 关键：边距要够大，羽化才落在空白处
3. 缩放基准 = 产品实体高度（不是图片高度）
4. 底：径向渐变 255 - 32*r**3（中央纯白，只四角压暗）
5. 贴片用 rounded_rectangle(inset 18%) + GaussianBlur(min(size)*0.11) 羽化蒙版
6. 自适应装入 1080×1920：产品顶部落 30%H，整块贴片含边距必须装得下，否则按比例缩小
7. ffmpeg: scale=2160:3840, zoompan 缓慢推近 1.0→1.07, eq brightness=0.012 saturation=1.06
```

### 4 个踩过的坑（都验证过）
| 坑 | 现象 | 修法 |
|---|---|---|
| 阈值太严把阴影留下 | 产品周围一圈**白/灰矩形框** | 官方图背景是纯白(255)，但**产品左右紧邻有 ~230 的灰带**（影棚渐变），阈值 228 抠不掉 → 换「留 30% 边距 + 大羽化」而不是死抠 |
| 硬贴裁切框 | 画面上出现**矩形接缝** | 硬贴只在贴片外缘也是 255 时才无缝；有灰带必须羽化 |
| 贴片比画布高 | **产品下半截被切**（Haier 消失） | 加"自适应装入画布"钳制（见步骤 6） |
| scipy 不在 mpt-venv | `ModuleNotFoundError: scipy` | 用 `PIL.ImageDraw.floodfill`（C 实现，秒级）做边境洪泛，比 numpy BFS 快 |

### 交付验收（必做）
- 抽帧看：产品完整（logo 不被切）、无白框/接缝、花字字幕不重叠
- STT 回读音频，比对烧入字幕是否一致

## 三、参考样片「逼真」的真相（逐帧放大验出，2026-09-15）
用户发来的 3 条"别人做的很逼真"样片（吹风机 1 条 + 迷你剃须刀 2 条）：
- 结构 = **真人画面 + 旁白口播 + 音乐 + 大字红底字幕/彩色花字**，15s 与 30s 两种
- 把样片里那个剃须刀**放大到像素级**后：是「矮胖筒身 + 金色凸面网头 + 银圈 + Haier」
  → **和我们真机（修长 1.9:1 + 顶部平金网）也不一致**，也就是说**他们也没做到形态还原**
- 结论：用户认可的"逼真"= **专业广告观感**（低照度暖光/浅景深/西装或商务场景/特写节奏/后期包装），
  不是"像素级还原真机"。别再死磕 1.9:1 修长比例 —— 强推修长反而把产品生成成"电子烟状"（实测 v4/v5 退步）
- 可复制的四条：①画面语汇（暖光/浅景深/商务场景）②主角跨镜一致 ③产品特写交给官方素材、人物镜头里产品不抢镜 ④后期：大字字幕+彩色花字+旁白+15-30s 完整叙事

## 四、三条硬教训（2026-09-15 用户第二轮反馈"那张裁剪的静态图太难看了，配音不好"）
### ❌ 官方静图「抠图/羽化/满画面」三种做法都不干净 —— 别再试了
`正面图.png` 这类官方产品图**产品左右两侧自带 ~230 的浅灰带**（影棚渐变/阴影），后果：
- 抠图（阈值228/235）→ 灰带留在 alpha 里 → 贴到任何底上都是**一个灰矩形框**
- 提高阈值到 222 → **把银色机身挖穿**（实测中轴不透明率仅 40.2%）
- 直接满画面裁 9:16 → **灰带仍以矩形边界露出来**（用户判"裁剪的静态图太难看"）
**结论：静图不要做镜头**。产品特写一律用"同一支片子里的 AI 特写镜头"（形态已被用户认可那种），
真要上官方图，只能用「官方拉页图 + 满画面 + 推近」并接受它就是图文卡（v6 被批 PPT）。

### ❌ 万相分段**没有**烧入字幕（原本的错误假设）
`/tmp/ad3/v2_seg*.mp4` 只有画面+自带音频，**没有任何烧入文字**。
我一度以为"烧入字幕=配音文本、必须逐字对齐" → 白做。正确做法：
**画面拿到手先抽帧确认有没有文字**，没有就自己上 ASS（`subtitles=xx.ass`），字幕文本随我写。

### ❌ 不要用万相自带音频做配音
用户评价原话：**「配音不好」**（万相生成的语音含混、口音怪）。
**全部替换成我方 edge-tts**：`zh-CN-XiaoxiaoNeural` + 按目标时长自动调速（循环 +Δrate% 逼近 ±0.2s）。
实例：18字目标3.76s → rate=+18%；15字目标3.28s → +16%；18字目标4.62s → +0%。
音频矩阵下标：`0=anullsrc 静音底, 1..N=TTS(adelay), N+1=BGM(volume=0.10)`，用 `amix normalize=0` 合并。
