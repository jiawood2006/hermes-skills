# 影棚感配方 + 配音对齐 + 交付规格（2026-09-16 v10 实测）

## 一、影棚感 prompt 三段式（实测达标，可直接复用）
参数：`model=wan2.7-r2v` / `resolution:1080P` / `ratio:9:16` / `duration:10` /
`prompt_extend:false` / `watermark:false` / `media=[参考图×2(两张同向同比例) + 人物图(带 reference_voice)]`

```
①风格段：电影感商业广告。摄影棚布光：大柔光箱主光+侧逆光勾边，浅景深背景虚化，
        肤色通透真实有毛孔质感，画面干净高级，低饱和暖调，专业模特级妆发。
        画面中不要出现任何文字、字幕、水印、贴纸。
②产品硬约束段：修长圆柱，高度约为直径的1.9倍（74×39×39mm）；顶部整面金色网面刀头；
        网面下方一圈黑色环带；机身正面下部白色 Haier 字样。
        严禁画成矮胖杯状/细杆/两截式手柄+刷头；严禁两个 logo。
③分镜段：第1个镜头[0-5秒]…（场景+动作+开口说的话）…第2个镜头[5-10秒]…
```

**v10 实测结论（2 段 ×10s / 1080P / 约 20 元）**
- ✅ 用户要的「高级感」到位：浅灰无缝影棚背景 + 柔光 + 人物皮肤/妆发真实，比拼接/官方静图高一档
- ❌ 剩余保真缺口（照实说给用户，不要藏）：
  1. **金网刀头被画成「凹面放射编织网」**（像喇叭罩），真机是**平面蜂窝网** ← 最明显失真点
  2. **机身比例约 1.5:1**，未达官方 1.93:1（比早期"矮胖罐"好，但不精确）
  3. 局部手部/箱包特写略糊
- 修法：把「刀头为**平面**蜂窝网，禁止凹面/放射纹/编织纹」写死进②，**单段重 roll（10 元）**比整片重做划算

## 二、配音对齐（我方 TTS 贴回原说话窗口）
1. 对原始分段做**带时间戳 STT**（faster_whisper `word_timestamps=True`，取每句 start/end）→ 得到说话窗口
2. 我方 TTS（`zh-CN-XiaoxiaoNeural`）+ 循环调 `--rate` 逼近原窗口时长（目标 ±0.2s）
3. 🔴 **强制顺序不重叠**（本次实测踩到）：
   ```python
   if abs_at < last_end + 0.25: abs_at = last_end + 0.25   # 顺延到上一句之后
   last_end = abs_at + d
   ```
   同一段里两句都被模型挤在前 3 秒时，不防重叠会出现**两句叠着说**
4. 音频矩阵：`0=anullsrc 静音底, 1..N=TTS(adelay=<ms>|,volume=1.2), N+1=BGM(volume=0.10)`
   → `amix=inputs=N+2:normalize=0` → `alimiter=limit=0.95`；画面取用加 `-an`（丢弃万相自带音频）
5. 成品**STT 回读**：确认每句独立、无重叠、内容=我方文案

## 三、交付规格与成本（用户口径）
- 用户习惯 **15s 与 30s** 两种成片（样片实测 15.07s / 30.07s）；20s 只是中间产物
- 1080P（1 元/秒）：15s=15元 / 20s=20元 / 30s=30元；720P（0.6 元/秒）可省 40%
- 30s 版做法：3 段 ×10s；素材段总长 > 成片时长是正常的（剪掉即可），不算浪费
- 先出 1~2 段验证观感，方向对了再补段做长版 —— 别一次性把预算烧完

## 四、发送与探活
- >15MB 视频 `feishu_send_media.py` 前台常被 420s 超时 kill → 用 `background=true` + `notify_on_complete`，
  一条命令里串行发多个文件
- 百炼是否解锁**别拿真实任务试**：给视频/图像接口发**空 input** `{"model":M,"input":{}}` →
  `InvalidParameter`（如 "input.prompt should not be null"）= 已放行；`Arrearage` = 仍拦截。空参数不会真正计费
